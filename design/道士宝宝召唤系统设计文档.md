## 系统概述

Crystal 游戏的道士宝宝召唤系统是一个复杂的宠物系统，具有以下特点：

- **多种召唤物**：骷髅、神兽、圣天使等
- **动态属性**：基于技能等级和宠物等级计算
- **独立成长**：宠物可以通过战斗获得经验升级
- **强化技能**：宠物强化技能提供临时加成
- **智能AI**：支持多种行为模式

### 核心概念

| 概念 | 说明 | 取值范围 |
|------|------|----------|
| **PetLevel** | 当前宠物等级 | 0-7 |
| **MaxPetLevel** | 最大宠物等级 | 1-11 |
| **MagicLevel** | 召唤技能等级 | 0-3 |
| **TameTime** | 驯服时间（忠诚度） | 时间戳 |
| **PMode** | 宠物行为模式 | 枚举值 |

## 召唤物类型

### 1. 召唤骷髅（SummonSkeleton）

#### 基本信息
- **技能ID**：Spell.SummonSkeleton = 65
- **怪物名称**：BoneFamiliar（骨骼护卫）
- **召唤道具**：护身符（Amulet）ID = 1
- **最大数量**：2个
- **召唤延迟**：500ms
- **MP消耗**：BaseCost + LevelCost × 技能等级

#### 技能等级需求
| 技能等级 | 学习等级 | 宠物最大等级 | 特点 |
|---------|---------|-------------|------|
| 0级 | 22级 | 4级 | 基础召唤 |
| 1级 | 30级 | 5级 | 提升1级 |
| 2级 | 35级 | 6级 | 提升2级 |
| 3级 | 40级 | 7级 | 提升3级 |

**最大等级公式**：
```csharp
MaxPetLevel = 4 + magic.Level
// 0级技能：4级
// 1级技能：5级
// 2级技能：6级
// 3级技能：7级
```

#### 骷髅特点
- **优点**：召唤成本低，数量多
- **缺点**：属性较低，容易死亡
- **用途**：肉盾、诱饵


## 技能等级影响

### 双重等级系统

召唤物有**两个等级概念**：

#### 1. MagicLevel（技能等级）
- 玩家的召唤技能等级（0-3级）
- 影响**最大宠物等级**（MaxPetLevel）
- 通过升级技能提升

#### 2. PetLevel（宠物等级）
- 宠物当前等级（0到MaxPetLevel）
- 影响**当前属性加成**（HP、AC、DC等）
- 通过战斗获得经验升级

### 技能等级对最大等级的影响

#### 召唤骷髅
```csharp
MaxPetLevel = 4 + magic.Level
```

| 技能等级 | 最大宠物等级 | 说明 |
|---------|-------------|------|
| 0 | 4 | 骷髅最高4级 |
| 1 | 5 | 骷髅最高5级 |
| 2 | 6 | 骷髅最高6级 |
| 3 | 7 | 骷髅最高7级 |

#### 召唤神兽/圣天使
```csharp
MaxPetLevel = 1 + magic.Level * 2
```

| 技能等级 | 最大宠物等级 | 说明 |
|---------|-------------|------|
| 0 | 1 | 神兽/天使最高1级 |
| 1 | 3 | 神兽/天使最高3级 |
| 2 | 5 | 神兽/天使最高5级 |
| 3 | 7 | 神兽/天使最高7级 |

### 召唤时的初始化

```csharp
public void SummonSkeleton(UserMagic magic)
{
    // 创建骷髅
    MonsterObject skeleton = new MonsterObject(ObjectID)
    {
        Name = Settings.SkeletonName,
        PetLevel = magic.Level,  // 初始等级=技能等级
        MaxPetLevel = 4 + magic.Level,  // 最大等级
        Master = this,
        Target = null,
        TameTime = Envir.Time + (Settings.Minute * 60)  // 60分钟驯服
    };

    // 添加到地图
    CurrentMap.AddObject(skeleton);
    Pets.Add(skeleton);
}
```

## 宠物强化系统

### PetEnhancer（宠物强化技能）

#### 基本信息
- **技能ID**：Spell.PetEnhancer = 85
- **技能类型**：Buff技能
- **目标**：己方召唤物
- **持续时间**：基于SC计算

#### 强化效果计算

```csharp
public void MagicPetEnhancer(UserMagic magic)
{
    // 增益值计算
    int dcInc = 2 + target.Level * 2;      // DC加成
    int acInc = 4 + target.Level;           // AC加成

    // 持续时间计算
    int duration = Settings.Second * (
        GetAttackPower(Stats[Stat.MinSC], Stats[Stat.MaxSC]) +
        magic.GetPower()
    );

    // 应用增益
    target.Stats[Stat.MinDC] += dcInc;
    target.Stats[Stat.MaxDC] += dcInc;
    target.Stats[Stat.MinAC] += acInc;
    target.Stats[Stat.MaxAC] += acInc;

    // 设置Buff过期时间
    target.PetEnhancerExpireTime = Envir.Time + duration;
}
```

#### 强化效果示例

假设：
- 玩家SC：50-80
- 宠物等级：2级
- 技能等级：1级（magic.GetPower() ≈ 30）

**计算**：
```
DC加成 = 2 + 2 * 2 = 6
AC加成 = 4 + 2 = 6
持续时间 = 65 * (50 + 30) = 65 * 80 = 5,200秒 ≈ 87分钟
```

**结果**：
- 宠物DC +6
- 宠物AC +6
- 持续时间87分钟

### 宠物强化Buff堆叠

```csharp
// 宠物强化可以堆叠
if (target.PetEnhancerExpireTime > Envir.Time)
{
    // 已有Buff，延长持续时间
    target.PetEnhancerExpireTime += duration;
}
else
{
    // 无Buff，添加新Buff
    target.PetEnhancerExpireTime = Envir.Time + duration;
    // 应用属性加成
}
```

## 宠物AI行为

### 宠物行为模式（PetMode）

```csharp
public enum PetMode
{
    None = 0,              // 不行动
    MoveOnly = 1,          // 只跟随
    AttackOnly = 2,        // 只攻击
    Both = 3,              // 跟随并攻击
    FocusMasterTarget = 4  // 攻击主人的目标
}
```

### 行为逻辑

#### 攻击判定

```csharp
public bool ShouldAttack()
{
    return Master.PMode == PetMode.AttackOnly ||
           Master.PMode == PetMode.Both ||
           Master.PMode == PetMode.FocusMasterTarget;
}
```

#### 移动判定

```csharp
public bool ShouldMove()
{
    return Master.PMode == PetMode.MoveOnly ||
           Master.PMode == PetMode.Both ||
           Master.PMode == PetMode.FocusMasterTarget;
}
```

#### 目标选择

```csharp
public MapObject GetTarget()
{
    // FocusMasterTarget 模式
    if (Master.PMode == PetMode.FocusMasterTarget)
    {
        return Master.Target;  // 攻击主人的目标
    }

    // 其他模式：自动选择最近的敌人
    return GetNearestEnemy();
}
```

### AI流程

```
宠物AI循环
  ↓
检查行为模式
  ├─ None → 不行动
  ├─ MoveOnly → 跳转到移动逻辑
  ├─ AttackOnly → 跳转到攻击逻辑
  ├─ Both → 执行移动和攻击逻辑
  └─ FocusMasterTarget → 跟随并攻击主人目标
  ↓
攻击逻辑（如果允许攻击）
  ├─ 检查目标
  ├─ 检查射程
  ├─ 检查冷却时间
  └─ 执行攻击
  ↓
移动逻辑（如果允许移动）
  ├─ 检查主人距离
  ├─ 距离 > 3 → 移动靠近
  └─ 距离 ≤ 3 → 停止移动
  ↓
检查忠诚度
  ├─ TameTime < 当前时间 → 宠物消失
  └─ TameTime ≥ 当前时间 → 继续
  ↓
AI循环结束
```
