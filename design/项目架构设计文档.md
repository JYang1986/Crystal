# Crystal Mir2 项目架构设计文档

## 1. 项目概述

### 1.1 项目简介
本项目是基于 Crystal 源码的传奇(Mir2)开源实现，是一个完整的 MMORPG 游戏框架，包含客户端、服务端及配套工具。

| 属性 | 说明 |
|------|------|
| **开发语言** | C# |
| **.NET 版本** | .NET 8.0 |
| **架构模式** | Windows Forms + DirectX (SlimDX) |
| **原始项目** | https://github.com/Suprcode/Crystal |
| **社区** | LOMCN (Legend of Mir Community Network) |

### 1.2 解决方案结构
```
Legend of Mir.sln
├── Client                  # 游戏客户端
├── Shared                  # 共享库
├── Server.Library          # 服务端核心库
├── Server.MirForms         # 服务端管理界面
├── AutoPatcherAdmin        # 补丁管理后台（工具）
├── LibraryEditor           # 资源库编辑器（工具）
├── LibraryViewer           # 资源库查看器（工具）
├── PatcherWebSite          # Web补丁网站
└── Controls/
    └── FixedListViewControl/ # 自定义控件
```

## 5. 网络协议架构

### 5.1 协议概述
项目使用自定义二进制协议，基于 TCP 连接。

| 特性 | 说明 |
|------|------|
| **序列化** | BinaryReader/Writer |
| **基类** | Packet (位于 Shared) |
| **标识** | 短整型索引号 |
| **压缩** | 支持数据包压缩 |

### 5.2 数据包结构
```
┌─────────────┬─────────────┬─────────────────┐
│ Packet Size │ Packet Index│    Payload      │
│   (2 bytes) │   (2 bytes) │  (variable)     │
└─────────────┴─────────────┴─────────────────┘
```

### 5.3 数据包定义文件

| 文件 | 命名空间 | 行数 | 方向 |
|------|----------|------|------|
| ClientPackets.cs | ClientPackets | 2,289 | 客户端 → 服务端 |
| ServerPackets.cs | ServerPackets | 5,649 | 服务端 → 客户端 |

### 5.4 常见数据包类型

**客户端发送 (ClientPackets)：**
| 数据包 | 功能 |
|--------|------|
| ClientVersion | 版本校验 |
| KeepAlive | 心跳保活 |
| Login | 登录请求 |
| CreateCharacter | 创建角色 |
| DeleteCharacter | 删除角色 |
| Move | 移动 |
| Attack | 攻击 |
| Chat | 聊天 |
| UseItem | 使用物品 |

**服务端发送 (ServerPackets)：**
| 数据包 | 功能 |
|--------|------|
| Connected | 连接成功 |
| ClientVersion | 版本校验结果 |
| Login | 登录响应 |
| NewCharacter | 新角色信息 |
| PlayerUpdate | 玩家状态更新 |
| ObjectPlayer | 其他玩家信息 |
| ObjectMonster | 怪物信息 |
| Chat | 聊天消息 |

### 5.5 数据包同步要求
⚠️ **重要：** 修改数据包结构时必须同时更新客户端和服务端：
1. 在 ClientPackets.cs 和 ServerPackets.cs 中添加新数据包
2. 更新 PacketIds 枚举（在 Shared 中）
3. 确保 ReadPacket 和 WritePacket 的字段顺序一致
4. 双方都需要重新编译

## 11. 开发指南

### 11.1 添加新功能

#### 添加新物品
1. 在 Shared 的 `ItemType` 枚举中添加类型
2. 在 `Server/MirDatabase/ItemInfo.cs` 中定义结构
3. 更新 `Envir/ItemInfo.json` 配置文件
4. 在客户端和服务端处理相关数据包

#### 添加新怪物
1. 继承 `Server/MirObjects/Monsters/MonsterObject.cs`
2. 重写攻击和移动逻辑
3. 在 `MonsterInfo.cs` 中添加配置
4. 更新 `Envir/MonsterInfo.json`

#### 添加新技能
1. 在 `MagicInfo.cs` 中定义技能属性
2. 在 Shared 的 `Spell` 枚举中添加 ID
3. 客户端：在 `Client/MirObjects/SpellObject.cs` 中添加渲染逻辑
4. 服务端：在 `Server/MirObjects/PlayerObject.cs` 中添加施放逻辑
5. 定义数据包用于同步技能效果

#### 添加新地图
1. 在 `MapInfo.cs` 中配置地图属性
2. 将地图文件放入 `Envir/Maps/` 目录
3. 配置刷新点和 NPC
4. 更新传送点数据

### 11.2 调试技巧

**客户端调试：**
- 查看 `Client/Settings.cs` 配置
- 检查 DirectX 设备初始化日志
- 使用断点调试 `GameScene.cs` 游戏循环

**服务端调试：**
- 查看 `Server/Settings.cs` 配置
- 检查 `Envir.cs` 的数据加载日志
- 使用 GM 命令进行测试

**网络调试：**
- 在 `Packet.cs` 中添加日志输出
- 检查数据包索引是否匹配
- 验证序列化顺序
