# Mir2 怪物物品爆率系统设计文档

## 1. 系统概述

### 1.1 功能简介
怪物物品爆率系统是 Mir2 游戏的核心经济系统之一，负责管理怪物死亡时掉落物品和金币的逻辑。该系统支持：
- 基于概率的物品掉落
- 金币掉落（带随机范围）
- 玩家爆率加成
- 任务物品过滤
- 全服掉落通知

### 1.2 核心文件

| 文件 | 位置 | 功能 |
|------|------|------|
| MonsterInfo.cs | Server/MirDatabase/ | 怪物信息定义，包含 DropInfo 列表 |
| MonsterObject.cs | Server/MirObjects/ | 怪物对象，处理死亡掉落逻辑 |
| MapObject.cs | Server/MirObjects/ | 地图对象基类，定义爆率加成属性 |
| Envir.cs | Server/MirEnvir/ | 环境管理，创建掉落物品 |
| Settings.cs | Server/ | 全局配置，爆率和金币设置 |

### 1.3 掉落配置文件
```
Server/Envir/Drops/
├── 鸡.txt              # 鸡的掉落配置
├── 鹿.txt              # 鹿的掉落配置

└── ... (每个怪物一个配置文件)
```

## 3. 掉落配置文件格式

### 3.1 配置文件位置
配置文件位于：`Server/Envir/Drops/[怪物名称].txt`

### 3.2 配置文件格式
每行代表一个掉落项，格式如下：

```
;注释行（以分号开头）
1/物品名称 [Q]
1/Gold 金币数量
```

**格式说明：**
- `1/` - 固定前缀，表示掉落概率
- `物品名称` - 与 ItemInfo 数据库中的名称匹配
- `[Q]` - 可选标记，表示该物品为任务物品
- `Gold` - 金币关键字
- `金币数量` - 基础金币数量

## 4. 掉落计算逻辑

### 4.1 掉落触发流程

```csharp
            // ...
        }
        else
        {
            // 物品掉落处理
            // ...
        }
    }
}
```

### 4.2 掉落概率计算公式

#### 4.2.1 基础概率
```
掉落概率 = 1 / Chance
```

例如：
- `Chance = 10` → 10% 掉落率
- `Chance = 100` → 1% 掉落率

#### 4.2.2 应用全局爆率倍率
```
调整后概率 = 1 / (Chance / DropRate)
```

`Settings.DropRate` 在 [Server/Settings.cs:92](../Server/Settings.cs#L92) 定义：
```csharp
public static float DropRate = 1F;
```

例如：
- `DropRate = 1.0` → 无变化
- `DropRate = 2.0` → 掉落率翻倍
- `DropRate = 0.5` → 掉落率减半

#### 4.2.3 应用玩家爆率加成
```
最终概率分母 = 调整后概率分母 × (1 - ItemDropRateOffset / 100)
```

`ItemDropRateOffset` 是玩家属性，例如：
- `ItemDropRateOffset = 10` → 掉落率提升 10%
- `ItemDropRateOffset = 50` → 掉落率提升 50%

#### 4.2.4 综合公式示例
假设：
- 配置：`Chance = 100`
- 全局爆率：`DropRate = 1.0`
- 玩家加成：`ItemDropRateOffset = 20`

计算过程：
```
1. 基础分母 = 100
2. 全局调整后 = 100 / 1.0 = 100
3. 玩家加成后 = 100 - (100 × 20 / 100) = 80
4. 最终掉落率 = 1 / 80 = 1.25%
```

### 4.3 金币掉落逻辑
位于 [Server/MirObjects/MonsterObject.cs:767-782](../Server/MirObjects/MonsterObject.cs#L767-L782)

```csharp
if (drop.Gold > 0)
{
    // 计算金币范围（基础值的 50% ~ 150%）
    int lowerGoldRange = (int)(drop.Gold / 2);
    int upperGoldRange = (int)(drop.Gold + drop.Gold / 2);

    // 应用玩家金币爆率加成
    if (EXPOwner != null && EXPOwner.GoldDropRateOffset > 0)
        lowerGoldRange += (int)(lowerGoldRange * (EXPOwner.GoldDropRateOffset / 100));

    if (lowerGoldRange > upperGoldRange) lowerGoldRange = upperGoldRange;

    // 随机金币数量
    int gold = Envir.Random.Next(lowerGoldRange, upperGoldRange);

    if (gold <= 0) continue;

    if (!DropGold((uint)gold)) return;
}
```

**金币计算公式：**

```
金币范围 = [Gold/2, Gold + Gold/2]
         = [Gold × 0.5, Gold × 1.5]

玩家加成后下限 = 下限 × (1 + GoldDropRateOffset / 100)

最终金币 = Random(下限, 上限)
```

### 4.5 掉落范围和保护

```csharp
protected virtual bool DropItem(UserItem item)
{
    // 检查地图是否允许掉落
    if (CurrentMap.Info.NoDropMonster)
        return false;

    // 创建物品对象
    ItemObject ob = new ItemObject(this, item)
    {
        Owner = EXPOwner,                           // 掉落归属
        OwnerTime = Envir.Time + Settings.Minute,   // 归属保护时间（60秒）
    };

    // 全服掉落通知
    if (!item.Info.GlobalDropNotify)
        return ob.Drop(Settings.DropRange);

    foreach (var player in Envir.Players)
    {
        player.ReceiveChat($"{Name}掉落了{item.FriendlyName}。", ChatType.System2);
    }

    return ob.Drop(Settings.DropRange);
}
```

### 4.6 金币掉落特殊处理
位于 [Server/MirObjects/MonsterObject.cs:827-848](../Server/MirObjects/MonsterObject.cs#L827-L848)

```csharp
protected virtual bool DropGold(uint gold)
{
    // 检查是否直接给予玩家
    if (EXPOwner != null && EXPOwner.CanGainGold(gold) && !Settings.DropGold)
    {
        EXPOwner.WinGold(gold);
        return true;
    }

    // 分堆掉落（超过 MaxDropGold 时分堆）
    uint count = gold / Settings.MaxDropGold == 0 ? 1 : gold / Settings.MaxDropGold + 1;
    for (int i = 0; i < count; i++)
    {
        ItemObject ob = new ItemObject(this, i != count - 1 ? Settings.MaxDropGold : gold % Settings.MaxDropGold)
        {
            Owner = EXPOwner,
            OwnerTime = Envir.Time + Settings.Minute,
        };

        ob.Drop(Settings.DropRange);
    }

    return true;
}
```

**金币配置参数：**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `MaxDropGold` | 2000 | 单堆金币上限 |
| `DropGold` | true | 是否掉落金币到地面（false 时直接进入背包） |

## 5. 配置加载流程

### 5.1 LoadDrops 方法
位于 [Server/MirDatabase/MonsterInfo.cs:154-205](../Server/MirDatabase/MonsterInfo.cs#L154-L205)

```csharp
public void LoadDrops()
{
    Drops.Clear();
    string path = Path.Combine(Settings.DropPath, Name + ".txt");

    // 文件不存在时创建模板
    if (!File.Exists(path))
    {
        string[] contents = new[]
        {
            ";Pots + Other", string.Empty, string.Empty,
            ";Weapons", string.Empty, string.Empty,
            ";Armour", string.Empty, string.Empty,
            ";Helmets", string.Empty, string.Empty,
            ";Necklace", string.Empty, string.Empty,
            ";Bracelets", string.Empty, string.Empty,
            ";Rings", string.Empty, string.Empty,
            ";Shoes", string.Empty, string.Empty,
            ";Belts", string.Empty, string.Empty,
            ";Stone",
        };

        File.WriteAllLines(path, contents);
        return;
    }

    // 读取并解析配置文件
    string[] lines = File.ReadAllLines(path);

    for (int i = 0; i < lines.Length; i++)
    {
        if (lines[i].StartsWith(";") || string.IsNullOrWhiteSpace(lines[i])) continue;

        DropInfo drop = DropInfo.FromLine(lines[i]);
        if (drop == null)
        {
            SMain.Enqueue(string.Format("Could not load Drop: {0}, Line {1}", Name, lines[i]));
            continue;
        }

        Drops.Add(drop);
    }

    // 排序：金币在后，按物品类型排序
    Drops.Sort((drop1, drop2) =>
    {
        if (drop1.Gold > 0 && drop2.Gold == 0)
            return 1;
        if (drop1.Gold == 0 && drop2.Gold > 0)
            return -1;

        return drop1.Item.Type.CompareTo(drop2.Item.Type);
    });
}
```

### 5.2 FromLine 解析方法
位于 [Server/MirDatabase/MonsterInfo.cs:283-308](../Server/MirDatabase/MonsterInfo.cs#L283-L308)

```csharp
public static DropInfo FromLine(string s)
{
    string[] parts = s.Split(new[] {' '}, StringSplitOptions.RemoveEmptyEntries);

    DropInfo info = new DropInfo();

    // 解析概率（格式：1/数字）
    if (!int.TryParse(parts[0].Substring(2), out info.Chance)) return null;

    // 解析金币掉落
    if (string.Compare(parts[1], "Gold", StringComparison.OrdinalIgnoreCase) == 0)
    {
        if (parts.Length < 3) return null;
        if (!uint.TryParse(parts[2], out info.Gold) || info.Gold == 0) return null;
    }
    // 解析物品掉落
    else
    {
        info.Item = SMain.Envir.GetItemInfo(parts[1]);
        if (info.Item == null) return null;

        // 检查任务物品标记
        if (parts.Length > 2)
        {
            string dropRequirement = parts[2];
            if (dropRequirement.ToUpper() == "Q") info.QuestRequired = true;
        }
    }

    return info;
}
```

### 6.2 可能的加成来源

| 来源 | 属性 | 说明 |
|------|------|------|
| 装备属性 | `ItemDropRateOffset` | 套装效果、幸运装备 |
| 药水/BUFF | `ItemDropRateOffset` | 爆率药水 |
| VIP 等级 | `GoldDropRateOffset` | VIP 金币加成 |
| 行会技能 | 两者 | 行会科技加成 |
| 活动加成 | 两者 | 全服活动 |

### 6.3 加成计算顺序
```
1. 基础概率分母 = Chance
2. 全局倍率调整 = 分母 / DropRate
3. 玩家加成调整 = 分母 × (1 - ItemDropRateOffset / 100)
4. 最终判定 = Random.Next(调整后分母) == 0
```

## 12. 常见问题

### Q1: 为什么物品不掉落？
可能原因：
1. 配置文件中 Chance 值太高（概率太低）
2. 物品标记为 `QuestRequired` 但未满足条件
3. 地图设置了 `NoDropMonster = true`
4. 玩家已有唯一物品

### Q2: 如何提高爆率？
方法：
1. 调整全局 `DropRate`
2. 给玩家添加 `ItemDropRateOffset` 加成
3. 使用爆率药水/BUFF

### Q3: 金币掉落为什么不进背包？
原因：
- `Settings.DropGold = true` 时掉落到地面
- `Settings.DropGold = false` 且玩家有足够金币容量时直接进入背包

### Q4: 如何设置必掉物品？
将 Chance 设置为 1：
```txt
1/必掉物品名称
```

### Q5: 如何设置极低概率掉落？
将 Chance 设置为高值：
```txt
1/超级稀有装备 1000  ; 0.1% 掉落率
```
