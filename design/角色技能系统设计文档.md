## 系统概述

Crystal 游戏采用经典 MMORPG 的技能系统设计，具有以下特点：

- **五大职业**：战士、法师、道士、刺客、弓手
- **技能类型多样**：攻击、防御、辅助、召唤、控制等
- **技能等级系统**：每个技能最高3级
- **技能熟练度**：使用技能获得经验，升级提升效果
- **冷却时间**：每个技能独立的CD系统
- **MP消耗**：施法需要消耗魔法值

## 技能系统架构

### 核心数据结构

#### MagicInfo（技能定义）

```csharp
public class MagicInfo
{
    public string Name;                      // 技能名称
    public Spell Spell;                      // 技能枚举类型
    public byte BaseCost;                    // 基础MP消耗
    public byte LevelCost;                   // 每级额外MP消耗
    public byte Icon;                        // 技能图标ID
    public byte Level1, Level2, Level3;      // 三个等级的需求等级
    public ushort Need1, Need2, Need3;       // 升级所需熟练度
    public uint DelayBase;                   // 基础冷却时间（毫秒）
    public uint DelayReduction;              // 每级减少的冷却时间
    public ushort PowerBase;                 // 基础攻击力
    public ushort PowerBonus;                // 每级攻击力加成
    public ushort MPowerBase;                // 基础魔法攻击力
    public ushort MPowerBonus;               // 每级魔法攻击力加成
    public float MultiplierBase;             // 基础伤害倍率
    public float MultiplierBonus;            // 每级伤害倍率加成
    public byte Range = 9;                   // 技能范围
    public int MPower(ushort level) => MPowerBase + (level * MPowerBonus);
    public int Power(ushort level) => PowerBase + (level * PowerBonus);
}
```

#### UserMagic（玩家技能）

```csharp
public class UserMagic
{
    public Spell Spell;                      // 技能类型
    public MagicInfo Info;                   // 技能定义信息
    public byte Level;                       // 技能等级（0-3）
    public byte Key;                         // 快捷键位置
    public ushort Experience;                // 技能熟练度经验
    public bool IsTempSpell;                 // 是否临时技能
    public long CastTime;                    // 上次施法时间
}
```

## 技能学习与升级

### 技能学习条件

```csharp
// 检查是否可以学习技能
public bool CanLearnSpell(Spell spell)
{
    // 1. 检查职业匹配
    if (!SpellMatchesClass(spell, Class)) return false;

    // 2. 检查等级要求
    if (Level < GetRequiredLevel(spell)) return false;

    // 3. 检查是否已学习
    if (HasSpell(spell)) return false;

    // 4. 检查技能书（如需要）
    if (RequiresSpellBook(spell) && !HasSpellBook(spell)) return false;

    return true;
}
```

### 技能升级机制

```csharp
public void LevelMagic(UserMagic magic)
{
    // 获得技能经验（1-3点随机）
    byte exp = (byte)(Envir.Random.Next(3) + 1);

    // 导师系统加成
    if (Settings.MentorSkillBoost && HasMentor())
        exp *= 2;

    // 技能经验获取倍率
    exp *= (byte)Math.Min(byte.MaxValue, Stats[Stat.SkillGainMultiplier]);

    int oldLevel = magic.Level;

    switch (magic.Level)
    {
        case 0: // 0级升1级
            if (Level < magic.Info.Level1) return;
            magic.Experience += exp;
            if (magic.Experience >= magic.Info.Need1)
            {
                magic.Level++;
                magic.Experience = (ushort)(magic.Experience - magic.Info.Need1);
                RefreshStats();
            }
            break;

        case 1: // 1级升2级
            if (Level < magic.Info.Level2) return;
            magic.Experience += exp;
            if (magic.Experience >= magic.Info.Need2)
            {
                magic.Level++;
                magic.Experience = (ushort)(magic.Experience - magic.Info.Need2);
                RefreshStats();
            }
            break;

        case 2: // 2级升3级
            if (Level < magic.Info.Level3) return;
            magic.Experience += exp;
            if (magic.Experience >= magic.Info.Need3)
            {
                magic.Level++;
                magic.Experience = 0;
                RefreshStats();
            }
            break;

        case 3: // 已满级
            return;
    }

    // 升级成功通知
    if (magic.Level > oldLevel)
    {
        ReceiveChat($"技能 {magic.Info.Name} 升级到 {magic.Level} 级！");
    }
}
```

public bool CanCastSpell(UserMagic magic)
{
    // 1. 检查技能是否已学习
    if (magic == null) return false;

    // 2. 检查冷却时间
    if (CMain.Time < magic.CastTime + magic.GetDelay()) return false;

    // 3. 检查MP
    int cost = MagicCost(magic);
    if (MP < cost) return false;

    // 4. 检查状态
    if (Dead || Poison == PoisonType.Paralysis || Poison == PoisonType.Stun)
        return false;

    // 5. 检查范围
    if (Target != null && !InRange(Target.Location, magic.Info.Range))
        return false;

    return true;
}

## 技能伤害计算

### 伤害计算公式

```csharp
public int GetDamage(int DamageBase)
{
    // 伤害 = (基础伤害 + 技能威力) × 技能倍率
    return (int)((DamageBase + GetPower()) * GetMultiplier());
}

public int GetPower()
{
    // 技能威力 = (魔法攻击力 / 4) × (技能等级 + 1) + 基础威力
    return (int)Math.Round((MPower() / 4F) * (Level + 1) + DefPower());
}

private int MPower()
{
    // 魔法攻击力 = 基础值 + 技能等级 × 加成 + 随机浮动
    return Info.MPowerBase + (Level * Info.MPowerBonus) +
           Envir.Random.Next(Info.MPowerBonus);
}

private int DefPower()
{
    // 基础威力 = 基础值 + 技能等级 × 加成 + 随机浮动
    return Info.PowerBase + (Level * Info.PowerBonus) +
           Envir.Random.Next(Info.PowerBonus);
}

public float GetMultiplier()
{
    // 技能倍率 = 基础倍率 + 技能等级 × 倍率加成
    return Info.MultiplierBase + (Level * Info.MultiplierBonus);
}
```

### 完整伤害公式

```
最终伤害 = [基础伤害 + ((随机(MPowerBase ~ MPowerBase+MPowerBonus) / 4) × (技能等级 + 1) + 随机(PowerBase ~ PowerBase+PowerBonus))] × (MultiplierBase + 技能等级 × MultiplierBonus)
```

### 伤害计算示例

**场景**：
- 玩家使用火球术（FireBall）
- 技能等级：2级
- MagicInfo 配置：
  - MPowerBase = 10, MPowerBonus = 5
  - PowerBase = 20, PowerBonus = 10
  - MultiplierBase = 1.0, MultiplierBonus = 0.2
- 玩家基础伤害：100

**计算过程**：
1. MPower = 10 + (2 × 5) + Random(5) = 20 + 3 = 23
2. DefPower = 20 + (2 × 10) + Random(10) = 40 + 5 = 45
3. GetPower = (23 / 4) × (2 + 1) + 45 = 17.25 + 45 = 62
4. GetMultiplier = 1.0 + (2 × 0.2) = 1.4
5. 最终伤害 = (100 + 62) × 1.4 = 226

**结果**：造成 226 点伤害
