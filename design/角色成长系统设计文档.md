## 系统概述

Crystal 游戏采用**多维度成长**系统设计，具有以下特点：

- **等级上限**：500级
- **非线性成长**：经验值指数级增长
- **职业差异化**：每个职业独特的属性成长曲线
- **多重成长线**：等级、技能、英雄、导师并行
- **惩罚机制**：等级差经验惩罚

### 成长维度

| 维度 | 说明 | 上限/限制 |
|------|------|-----------|
| **等级** | 角色等级 | 500级 |
| **技能等级** | 单个技能等级 | 3级 |
| **英雄系统** | 英雄等级 | 500级 |
| **导师系统** | 导师关系 | 10级差距 |

### 升级流程

```
获得经验值
  ↓
检查等级差惩罚
  ├─ 玩家等级 ≤ 怪物等级+10 → 无惩罚
  └─ 玩家等级 > 怪物等级+10 → 应用惩罚公式
  ↓
应用经验倍率
  ├─ 全局经验率：Settings.ExpRate
  ├─ 新手公会：+5%
  └─ 其他加成
  ↓
增加当前经验值
  ↓
检查是否升级
  ├─ 当前经验 < 需要经验 → 继续积累
  └─ 当前经验 ≥ 需要经验 → 触发升级
  ↓
执行升级
  ├─ 等级 +1
  ├─ 经验值扣除
  ├─ 重新计算属性
  ├─ 恢复 HP/MP
  ├─ 检查技能升级
  └─ 广播升级效果
  ↓
升级完成
```

### 升级代码实现

```csharp
public void GainExp(long amount)
{
    // 经验值惩罚计算
    if (Level >= targetLevel + 10 && Settings.ExpMobLevelDifference)
    {
        amount -= (long)Math.Round(Math.Max(amount / 15, 1) *
            ((double)Level - (targetLevel + 10)));
    }

    if (amount <= 0) return;

    // 应用经验倍率
    amount = (long)(amount * Settings.ExpRate);

    // 新手公会额外5%经验
    if (InGuild && Guild.Level < 10)
    {
        amount += amount / 20;
    }

    // 增加经验值
    Experience += amount;

    // 检查是否升级
    while (Level < MaxLevel && Experience >= GetExpForLevel(Level + 1))
    {
        LevelUp();
    }
}

public virtual void LevelUp()
{
    Level++;
    Experience -= GetExpForLevel(Level);

    // 重新计算所有属性
    RefreshStats();
    RefreshLevelStats();

    // 恢复 HP/MP
    SetHP(Stats[Stat.HP]);
    SetMP(Stats[Stat.MP]);

    // 检查技能自动升级
    CheckSkills();

    // 广播升级效果
    BroadcastLevelUp();
}
```

## 属性成长系统

### 属性计算公式

所有基础属性使用统一的计算公式：

```csharp
public int Calculate(MirClass job, int level)
{
    // HP 特殊公式（二次方程）
    if (Type == Stat.HP && job == MirClass.Warrior)
    {
        return (int)(Base + (level / Gain + GainRate + level / 20F) * level);
    }
    else if (Type == Stat.HP)
    {
        return (int)(Base + (level / Gain + GainRate) * level);
    }

    // MP 特殊公式
    if (Type == Stat.MP)
    {
        if (job == MirClass.Wizard)
        {
            return (int)(Base + ((level / Gain + 2F) * 2.2F * level) + (level * GainRate));
        }
        else if (job == MirClass.Taoist)
        {
            return (int)(Base + (level / Gain * 2.2F * level) + (level * GainRate));
        }
        else
        {
            return (int)(Base + (level * Gain) + (level * GainRate));
        }
    }

    // 其他属性（DC/MC/SC/AC/MAC 等）
    return (int)(Base + (level / Gain));
}
```

## HP/MP成长

### HP 成长公式

#### 战士特殊公式（二次方程）

```csharp
HP = 14 + (level / 4 + 4.5 + level / 20F) * level

// 简化后：
HP = 14 + 0.25×level² + 4.7×level
```

**示例计算**（50级战士）：
```
HP = 14 + (50 / 4 + 4.5 + 50 / 20) × 50
   = 14 + (12.5 + 4.5 + 2.5) × 50
   = 14 + 19.5 × 50
   = 14 + 975
   = 989
```

#### 其他职业公式

```csharp
HP = Base + (level / Gain + GainRate) * level
```

**示例计算**（50级法师）：
```
HP = 14 + (50 / 15 + 1.8) × 50
   = 14 + (3.33 + 1.8) × 50
   = 14 + 5.13 × 50
   = 14 + 256.5
   ≈ 270
```

### MP 成长公式

#### 法师特殊公式

```csharp
MP = 13 + ((level / 5 + 2) * 2.2 * level) + (level * 0)

// 简化后：
MP = 13 + 2.2 × level² + 4.4 × level
```

#### 道士特殊公式

```csharp
MP = 13 + (level / 8 * 2.2 * level) + (level * 0)
```

#### 其他职业公式

```csharp
MP = Base + (level * Gain)
```

## 技能成长

### 技能等级系统

每个技能分为 **3 个等级**：

| 技能等级 | 需求等级 | 需要熟练度 | 属性提升 |
|---------|---------|-----------|----------|
| **0级（学习）** | Level1 | Need1 | 基础效果 |
| **1级** | Level2 | Need2 | 效果+30% |
| **2级** | Level3 | Need3 | 效果+60% |
| **3级（满级）** | - | - | 效果+100% |

### 技能熟练度获取

```csharp
public void LevelMagic(UserMagic magic)
{
    // 获得技能经验（1-3点随机）
    byte exp = (byte)(Envir.Random.Next(3) + 1);

    // 导师系统加成
    if (Settings.MentorSkillBoost && HasMentor())
    {
        exp *= 2;  // 导师在场，经验翻倍
    }

    // 技能经验获取倍率
    exp *= (byte)Math.Min(byte.MaxValue, Stats[Stat.SkillGainMultiplier]);

    switch (magic.Level)
    {
        case 0: // 0级升1级
            if (Level < magic.Info.Level1) return;
            magic.Experience += exp;
            if (magic.Experience >= magic.Info.Need1)
            {
                magic.Level++;
                magic.Experience = (ushort)(magic.Experience - magic.Info.Need1);
                RefreshStats();
            }
            break;

        case 1: // 1级升2级
            if (Level < magic.Info.Level2) return;
            magic.Experience += exp;
            if (magic.Experience >= magic.Info.Need2)
            {
                magic.Level++;
                magic.Experience = (ushort)(magic.Experience - magic.Info.Need2);
                RefreshStats();
            }
            break;

        case 2: // 2级升3级
            if (Level < magic.Info.Level3) return;
            magic.Experience += exp;
            if (magic.Experience >= magic.Info.Need3)
            {
                magic.Level++;
                magic.Experience = 0;
                RefreshStats();
            }
            break;

        case 3: // 已满级
            return;
    }

    // 升级成功通知
    if (magic.Level > oldLevel)
    {
        ReceiveChat($"技能 {magic.Info.Name} 升级到 {magic.Level} 级！");
    }
}
```

### 技能熟练度示例

**火球术**（FireBall）：
- **Level1**：7级可学，Need1=500熟练度
- **Level2**：15级可学，Need2=1000熟练度
- **Level3**：22级可学，Need3=2000熟练度

**升级计算**：
- 每次使用获得 1-3 点熟练度
- 有导师时翻倍（2-6 点）
- 需要使用约 167-500 次才能从 0级升到1级（无导师）

## 经验值系统

### 经验值获取来源

#### 1. 杀怪获得

```csharp
public void KillMonster(MonsterObject monster)
{
    // 基础经验值
    long exp = monster.Info.Exp;

    // 等级差惩罚
    if (Level >= monster.Info.Level + 10 && Settings.ExpMobLevelDifference)
    {
        long penalty = (long)Math.Round(Math.Max(exp / 15, 1) *
            ((double)Level - (monster.Info.Level + 10)));
        exp -= penalty;
    }

    if (exp <= 0) return;

    // 应用经验倍率
    exp = (long)(exp * Settings.ExpRate);

    // 新手公会额外5%
    if (InGuild && Guild.Level < 10)
    {
        exp += exp / 20;
    }

    // 获得经验
    GainExp(exp);
}
```

#### 2. 任务奖励

```csharp
public void CompleteQuest(QuestInfo quest)
{
    // 任务经验奖励
    long exp = quest.Info.ExpReward * Settings.ExpRate;

    // 新手公会额外5%
    if (InGuild && Guild.Level < 10)
    {
        exp += exp / 20;
    }

    GainExp(exp);
}
```

#### 3. 其他来源

- **宠物经验分享**：宠物击杀怪物分享经验
- **行会经验**：1%转化为行会经验
- **导师系统**：经验存储给导师

### 经验值惩罚机制

#### 惩罚公式

```csharp
if (Level >= targetLevel + 10)
{
    // 惩罚计算
    long penalty = (long)Math.Round(Math.Max(exp / 15, 1) *
        (Level - targetLevel - 10));
    exp -= penalty;
}
```

#### 惩罚示例

| 玩家等级 | 怪物等级 | 等级差 | 惩罚计算 | 最终经验 |
|---------|---------|--------|----------|----------|
| 20 | 10 | 10 | 无惩罚 | 100% |
| 21 | 10 | 11 | exp/15 × 1 | 93% |
| 25 | 10 | 15 | exp/15 × 5 | 67% |
| 30 | 10 | 20 | exp/15 × 10 | 33% |
| 35 | 10 | 25 | exp/15 × 15 | 0% |

**结论**：等级差距超过25级时无法获得经验。

## 特殊系统

### 导师系统（Mentor）

#### 导师设置

```csharp
public static byte MentorLevelGap = 10;       // 最大等级差距
public static byte MentorDuration = 7;        // 导师时长（天）
public static byte MenteeExpBank = 1;         // 学徒经验存储比例（1%）
public static bool MentorSkillBoost = true;   // 导师技能加成
```

#### 导师机制

**导师（Mentor）**：
- 需要比学徒高10级以上
- 接受学徒后获得经验存储
- 技能等级在学徒面前+1
- 对学徒伤害+10%

**学徒（Mentee）**：
- 每次获得经验时存储1%给导师
- 可以使用导师的技能（等级+1）
- 学徒等级超过导师+10级时自动解除关系

#### 导师经验计算

```csharp
// 学徒获得经验时
if (Info.Mentor != 0 && !Info.IsMentor)
{
    // 存储经验给导师
    MenteeEXP += (amount * Settings.MenteeExpBank) / 100;
}

// 导师解除关系时
public void EndMentorship()
{
    // 导师获得存储的经验
    GainExp(MenteeEXP);
    MenteeEXP = 0;
}
```

### 英雄系统（Hero）

#### 英雄配置

- **英雄上限**：每个玩家最多9个英雄
- **英雄等级**：独立计算，最高500级
- **经验值**：每级只需100点经验（固定）
- **技能系统**：英雄有独立的技能系统

#### 英雄经验获取

```csharp
// 英雄跟随玩家获得经验
public void HeroGainExp(long amount)
{
    amount *= Settings.ExpRate;
    Hero.Experience += amount;

    // 检查升级
    while (Hero.Level < MaxHeroLevel && Hero.Experience >= 100)
    {
        Hero.Level++;
        Hero.Experience -= 100;
        Hero.RefreshStats();
    }
}
```

#### 英雄创建条件

```csharp
public bool CanCreateHero()
{
    // 等级要求
    if (Level < 40) return false;

    // 检查道具
    if (!HasItem(HeroToken)) return false;

    // 检查英雄数量
    if (Heroes.Count >= 9) return false;

    return true;
}
```
