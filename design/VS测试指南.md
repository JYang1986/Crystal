# Mir2 本地化项目 - Visual Studio 测试指南

## 🎯 目标

使用 Visual Studio 2019 (v18) 编译并测试 Mir2 本地化项目

## 📋 准备工作

### 1. 确认 Visual Studio 版本

你已经安装：`D:\Program Files\Microsoft Visual Studio\18\Community`

这是 **Visual Studio 2019**，完全兼容。

### 2. 确认工作负荷

打开 Visual Studio Installer，确认已安装：
- ✅ .NET 桌面开发
- ✅ Windows SDK

如果未安装，运行 Visual Studio Installer 添加这些工作负荷。

## 🚀 开始测试

### 步骤 1: 打开解决方案

1. 打开 Visual Studio 2019
2. 选择 "打开项目或解决方案"
3. 导航到：`H:\github\mir2\Legend of Mir.sln`
4. 点击"打开"

**或者**：
- 直接双击 `H:\github\mir2\Legend of Mir.sln`

### 步骤 2: 等待项目加载

Visual Studio 会：
- 加载所有项目（Client、Server 等）
- 检查依赖关系
- 可能提示安装 .NET Framework 4.8（如果未安装）

### 步骤 3: 还原 NuGet 包（如果需要）

如果看到关于 NuGet 包的警告：
1. 右键点击解决方案
2. 选择"还原 NuGet 程序包"
3. 等待包还原完成

### 步骤 4: 设置启动项目

1. 在"解决方案资源管理器"中找到 `Client` 项目
2. 右键点击
3. 选择"设为启动项目"

### 步骤 5: 生成解决方案

**方式 A**: 使用菜单
- 点击菜单"生成" → "生成解决方案"
- 或按 `Ctrl+Shift+B`

**方式 B**: 仅生成 Client 项目
- 右键点击 `Client` 项目
- 选择"生成"

### 步骤 6: 查看编译结果

**"输出"窗口会显示**：
```
------ 已启动生成: 项目: Client, 配置: Debug Any CPU ------
...
========== 生成: 成功 X 个，失败 0 个，最新 0 个，跳过 X 个 ==========
```

### 步骤 7: 运行测试

**调试运行（推荐）**：
- 按 `F5`
- 可以查看调试输出和断点

**不调试运行**：
- 按 `Ctrl+F5`
- 性能稍好

## 🐛 处理编译错误

### 预期错误

由于 LocalGame 代码引用了服务端类型，可能会出现以下错误：

#### 错误 1: 缺少服务端类型

```
error CS0246: 未能找到类型或命名空间名"Server.MirDatabase"
```

**解决方案 A（推荐）: 添加 Server 项目引用**
1. 右键点击 `Client` 项目
2. 选择"添加" → "引用"
3. 在"项目"选项卡中，勾选 `Server`
4. 点击"确定"

**解决方案 B: 移除服务端依赖**
- 在 `LocalEnvir.cs` 中注释掉服务端类型的引用
- 使用简化版本的数据定义

#### 错误 2: System.Text.Json 缺失

```
error CS0234: 命名空间"System.Text"中不存在类型或命名空间名"Json"
```

**解决方案 A（推荐）: 安装 NuGet 包**
1. 右键点击 `Client` 项目
2. 选择"管理 NuGet 程序包"
3. 搜索 `System.Text.Json`
4. 点击"安装"

**解决方案 B: 改用其他 JSON 库**
- 使用 `Newtonsoft.Json`
- 或使用内置的 `JavaScriptSerializer`

#### 错误 3: 数据包类型不匹配

```
error CS0234: 命令空间"ClientPackets"中不存在类型或命名空间名"Move"
```

**解决方案**: 检查并更新数据包名称
- 查看 `ClientPackets.cs` 中的实际数据包名称
- 更新 `LocalNetworkBridge.cs` 中的引用

## ⚠️ 常见问题

### 问题 1: DirectX 引用错误

```
error: 找不到 Microsoft.DirectX.dll
```

**解决**: 确保 DirectX SDK 路径正确
- 检查 `Client\DirectX\` 目录
- 或从原始项目复制 DirectX DLL

### 问题 2: 资源文件缺失

```
运行时错误: 无法加载纹理库
```

**解决**: 需要游戏资源文件
- WIL/WTL 纹理库
- 地图文件
- 音效文件

**提示**: 这些文件需要从原始游戏复制

### 问题 3: 存档文件不存在

```
[LocalMode] 加载了 0 个本地角色
```

**这是正常的！** 首次运行没有存档。

**解决**:
1. 使用 Visual Studio 创建角色功能
2. 或手动创建测试存档 JSON 文件
