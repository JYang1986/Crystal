## 系统概述

Crystal 游戏采用**多层次、渐进式**的怪物难度曲线设计，具有以下特点：

- **等级范围**：1-100+级，覆盖玩家1-500级成长
- **难度分级**：普通/精英/稀有/Boss四级难度
- **动态平衡**：经验修正机制适应玩家等级
- **多样化AI**：85种AI类型提供丰富战斗体验
- **稀有度系统**：随机生成稀有度怪物，增加挑战性

### 核心设计理念

| 设计目标 | 实现方式 |
|---------|---------|
| **渐进式成长** | 怪物属性随等级线性/二次成长 |
| **挑战多样化** | 不同AI类型和技能组合 |
| **奖励激励** | 稀有度倍率和掉落率加成 |
| **动态平衡** | 等级差经验修正机制 |

### 等级差经验修正

#### 经验修正公式

```csharp
public uint GetExp(uint baseExp, int monsterLevel, int playerLevel)
{
    // 等级差
    int levelDiff = playerLevel - monsterLevel;

    // 如果玩家等级远高于怪物（>10级），减少经验
    if (levelDiff > 10)
    {
        int penalty = max(levelDiff - 10, 1);
        uint expReduction = (uint)(baseExp / 15 * penalty);
        return max(baseExp - expReduction, 1);
    }

    // 如果玩家等级低于怪物，增加经验
    if (levelDiff < -5)
    {
        int bonus = abs(levelDiff + 5);
        return baseExp * (1 + bonus * 0.1F);
    }

    return baseExp;
}
```

**经验修正表**：

| 等级差 | 经验系数 | 说明 |
|--------|---------|------|
| 玩家-11级或更多 | 每级-6.67% | 严重惩罚 |
| 玩家-10级 | 100% | 开始惩罚 |
| 玩家-5级到+5级 | 100%-150% | 正常范围 |
| 玩家-6级或更低 | 每级+10% | 奖励 |

### AI行为模式

#### 近战AI
```csharp
public override void ProcessTarget()
{
    // 1. 检查目标是否在攻击范围
    if (!InAttackRange())
    {
        // 移动到目标
        MoveTo(Target.CurrentLocation);
    }
    else
    {
        // 攻击目标
        Attack();
    }
}
```

#### 远程AI
```csharp
public override void ProcessTarget()
{
    // 1. 保持距离
    int desiredDistance = 4;  // 理想距离4格
    if (GetDistance(Target) > desiredDistance)
    {
        MoveTo(Target.CurrentLocation);
    }
    else if (GetDistance(Target) < desiredDistance - 1)
    {
        MoveAway(Target.CurrentLocation);  // 后撤
    }
    else
    {
        // 2. 远程攻击
        RangeAttack();
    }
}
```

#### 魔法AI
```csharp
public override void ProcessTarget()
{
    // 1. 检查MP
    if (MP < Info.MP)
    {
        // 等待MP恢复
        return;
    }

    // 2. 选择魔法技能
    if (CanUseMagicSkill())
    {
        MagicAttack();
    }
    else
    {
        // 3. 普通攻击
        Attack();
    }
}
```

#### 最终经验计算

```csharp
public uint GetFinalExperience(MonsterObject monster, PlayerObject player)
{
    // 1. 基础经验
    uint exp = monster.Info.Experience;

    // 2. 稀有度倍率
    exp = (uint)(exp * MonsterType.ExpMultiplier);

    // 3. 等级差修正
    exp = GetExpWithLevelDiff(exp, monster.Level, player.Level);

    // 4. 服务器经验倍率
    exp = (uint)(exp * Settings.ExpRate);

    // 5. 组队加成（可选）
    if (player.InTeam)
    {
        exp = (uint)(exp * Settings.ExpRateInTeam);
    }

    return exp;
}
```

#### 掉落率计算

```csharp
public bool CheckDrop(MonsterObject monster, DropInfo drop)
{
    // 1. 基础概率
    float chance = drop.Chance / 10000F;  // 转换为百分比

    // 2. 服务器掉落率修正
    chance /= Settings.DropRate;

    // 3. 稀有度加成
    switch (monster.MonsterType)
    {
        case MonsterType.Uncommon:
            chance *= 1.15F;
            break;
        case MonsterType.Rare:
            chance *= 1.35F;
            break;
        case MonsterType.Elite:
            chance *= 1.75F;
            break;
    }

    // 4. 幸运值加成（玩家属性）
    chance *= (1 + player.Luck / 100F);

    // 5. 随机判定
    return Envir.Random.NextDouble() < chance;
}
```

#### 金币掉落

```csharp
public uint DropGold(MonsterObject monster)
{
    // 1. 基础金币
    uint gold = monster.Info.Gold;

    // 2. 稀有度倍率
    gold = (uint)(gold * MonsterType.GoldMultiplier);

    // 3. 随机浮动（±20%）
    gold = (uint)(gold * (0.8F + Envir.Random.NextFloat(0.4F)));

    // 4. 上限限制
    gold = min(gold, Settings.MaxDropGold);  // 最大2000金币

    return gold;
}
```
