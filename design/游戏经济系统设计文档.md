## 系统概述

Crystal 游戏采用**多货币、多层次**的经济系统设计，具有以下特点：

- **主货币**：金币（Gold）
- **多货币体系**：金币、珍珠币、充值币
- **动态定价**：基于行会领地、耐久度、附加属性
- **风险机制**：强化失败损失材料
- **回收系统**：物品出售价格低于购买价格
- **通胀控制**：产出限制、消耗机制、复币体系

### 核心设计理念

| 设计目标 | 实现方式 |
|---------|---------|
| **防止通胀** | 金币产出上限、多重消耗 |
| **促进交易** | 行会领地折扣、拍卖系统 |
| **鼓励消费** | 强化、觉醒、修理费用 |
| **价值保护** | 耐久度影响、品质加成 |

## 商店买卖系统

### NPC商店定价机制

#### 价格率计算（PriceRate）

```csharp
public float PriceRate(PlayerObject player, bool baseRate = false)
{
    // 1. 获取NPC基础价格率（如80表示80%价格）
    float basePrice = callingNPC.Info.Rate / 100F;

    // 2. 检查是否为行会领地成员
    if (player.MyGuild != null &&
        player.MyGuild.Guildindex == callingNPC.Conq.GuildInfo.Owner)
    {
        // 行会成员：享受基础价格
        return basePrice;
    }
    else
    {
        // 非行会成员：额外收费
        // 公式：((基础价格 × NPC税率) + 基础价格) / 100
        return ((basePrice * callingNPC.Conq.GuildInfo.NPCRate) + basePrice) / 100F;
    }
}
```

#### 购买价格计算

```csharp
uint cost = goods.Price();  // 物品基础价格
cost = (uint)(cost * PriceRate(player));  // 应用价格率
```

**示例**：
| 场景 | 基础价格 | NPC税率 | 实际价格率 | 最终价格 |
|------|---------|---------|-----------|----------|
| 行会成员购买 | 100金币 | - | 80% | 80金币 |
| 非成员购买 | 100金币 | 120% | ((100×1.2)+100)/100 = 110% | 110金币 |

## 物品价值计算

### 耐久度对价格的影响

#### UserItem.Price() 方法

```csharp
public uint Price()
{
    uint p = Info.Price;  // 物品基础价格

    // 耐久度影响计算
    if (Info.Durability > 0)
    {
        // 计算每点耐久度的价值
        float r = ((Info.Price / 2F) / Info.Durability);

        // 根据最大耐久度计算基础价值
        p = (uint)(MaxDura * r);

        // 根据当前耐久度比例调整
        float duraRatio = MaxDura > 0 ? CurrentDura / (float)MaxDura : 0;

        // 最终价格 = 一半固定 + 一半按耐久度比例
        p = (uint)Math.Floor(p / 2F + ((p / 2F) * duraRatio) + Info.Price / 2F);
    }

    // 附加属性加成（每个属性+10%价值）
    p = (uint)(p * (AddedStats.Count * 0.1F + 1F));

    // 考虑物品数量
    return p * Count;
}
```

#### 耐久度价格示例

**场景**：
- 物品基础价格：1000金币
- 最大耐久度：100
- 当前耐久度：50
- 无附加属性

**计算过程**：
1. 每点耐久度价值：(1000 / 2) / 100 = 5
2. 基础价值：100 × 5 = 500
3. 耐久度比例：50 / 100 = 0.5
4. 最终价格：
   ```
   = 500/2 + (500/2 × 0.5) + 1000/2
   = 250 + 125 + 500
   = 875金币
   ```

**结论**：50%耐久度的物品售价为87.5%

## 合成费用系统

### 配方制作费用

#### RecipeInfo 结构

```csharp
public class RecipeInfo
{
    public UserItem Item;           // 制作结果
    public List<UserItem> Ingredients; // 材料列表
    public List<UserItem> Tools;     // 工具列表
    public byte Chance = 100;        // 成功率
    public uint Gold = 0;           // 金币消耗
}
```

#### 合成流程

```
开始制作
  ↓
检查材料
  ├─ 材料数量是否充足
  └─ 工具是否可用
  ↓
消耗金币
  ↓
成功率判定
  ├─ 成功率：Chance（如80%）
  ├─ 成功 → 继续下一步
  └─ 失败（20%）→ 材料销毁，制作失败
  ↓
消耗材料和工具耐久
  ↓
生成制作结果
  ↓
制作完成
```

#### 配方文件格式

```
[recipe]
amount 1          # 制作数量
chance 80         # 成功率80%
gold 1000          # 需要金币1000

[ingredients]
IronOre 5         # 铁矿石x5
Coal 3            # 煤x3

[tools]
Forge 1           # 熔炉x1
Hammer 1          # 铁锤x1
```

### 装备合成费用

#### CombineItem（装备合成）

```csharp
// 合成两个装备，叠加附加属性
public bool CombineItem(UserItem itemA, UserItem itemB)
{
    // 检查条件
    if (itemA.Info != itemB.Info) return false;

    // 15%几率材料装备被销毁
    if (Envir.Random.Next(100) < 15)
    {
        RemoveItem(itemB);
        return false;
    }

    // 叠加附加属性
    itemA.AddedStats.AddRange(itemB.AddedStats);
    RemoveItem(itemB);

    return true;
}
```

**风险**：15%几率材料装备被销毁

## 其他经济系统

### 修理费用

#### RepairPrice() 方法

```csharp
public uint RepairPrice()
{
    if (Info == null || Info.Durability == 0)
        return 0;

    // 基础价值计算
    var p = Info.Price;

    // 耐久度影响
    if (Info.Durability > 0)
    {
        p = (uint)Math.Floor(MaxDura * ((Info.Price / 2F) / Info.Durability) + Info.Price / 2F);

        // 附加属性加成
        p = (uint)(p * (AddedStats.Count * 0.1F + 1F));
    }

    // 修理费用 = 恢复到满耐久的价值 - 当前价值
    var cost = p * Count - Price();

    // 租赁物品修理费翻倍
    if (RentalInformation == null)
        return cost;

    return cost * 2;
}
```

**示例**：
- 物品基础价格：10,000金币
- 最大耐久度：100
- 当前耐久度：50
- 附加属性：2个

**计算**：
1. 每点耐久价值：(10000/2)/100 = 50
2. 满耐久价值：100 × 50 = 5000
3. 满耐久最终价值：5000/2 + 5000/2×1.0 + 10000/2 = 2500 + 2500 + 5000 = 10,000
4. 当前价值：8750（来自耐久度计算示例）
5. 修理费用：10,000 - 8,750 = 1,250金币

### 回收机制

#### 卖出价格低于购买价格

```csharp
// 买入价格
买入价 = 物品基础价格 × 价格率

// 卖出价格
卖出价 = 物品基础价格 × 耐久度比例 × 附加属性加成

// 结论：卖出价 < 买入价（不考虑市场波动）
```

**示例**：
- 物品基础价格：1000金币
- 买入价格率：80%
- 耐久度：50%
- 无附加属性

**计算**：
- 买入价：1000 × 80% = 800金币
- 卖出价：875金币（耐久度计算示例）
- 损失：875 - 800 = 75金币（约9.4%）
