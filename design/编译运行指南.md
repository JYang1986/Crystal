# Crystal Mir2 编译运行指南

## 1. 前置要求

### 1.1 软件要求

| 软件 | 版本要求 | 用途 | 下载地址 |
|------|----------|------|----------|
| Visual Studio 2022 | 17.8 或更高版本 | 编译项目 | https://visualstudio.microsoft.com/ |
| .NET SDK | 8.0 | 运行时和开发工具 | https://dotnet.microsoft.com/download/dotnet/8.0 |
| DirectX 9.0c | - | 客户端渲染 | https://www.microsoft.com/en-us/download/details.aspx?id=8109 |

### 1.2 Visual Studio 安装组件
安装 Visual Studio 2022 时需要选择：
- **.NET 桌面开发** 工作负载
- **Windows 10/11 SDK**（可选，用于最新功能）

### 1.3 硬件要求

**最低配置：**
- CPU: 双核 2.0GHz
- 内存: 4GB
- 显卡: 支持 DirectX 9
- 硬盘: 5GB 可用空间

**推荐配置：**
- CPU: 四核 3.0GHz+
- 内存: 8GB+
- 显卡: 独立显卡
- 硬盘: 10GB+ SSD

## 3. 编译服务端

### 3.1 使用 Visual Studio 编译

1. **打开解决方案**
   ```
   双击打开: H:\github\Crystal\Legend of Mir.sln
   ```

2. **设置服务端为启动项目**
   - 在"解决方案资源管理器"中右键点击 `Server.MirForms` 项目
   - 选择"设为启动项目"

3. **选择配置**
   - 顶部工具栏选择 `Release` 或 `Debug` 配置
   - 平台选择 `Any CPU`

4. **生成服务端**
   - 按 `Ctrl+Shift+B` 或点击"生成" → "生成解决方案"
   - 或右键 `Server.MirForms` 项目 → "生成"

5. **检查输出**
   - 输出目录: `H:\github\Crystal\Build\Server\`
   - 应该包含:
     ```
     Server.exe
     Server.exe.config
     Server.Library.dll
     Shared.dll
     ... (其他依赖 DLL)
     ```

### 3.2 使用 dotnet CLI 编译

打开命令提示符或 PowerShell：

```bash
# 切换到项目目录
cd H:\github\Crystal

# 编译整个解决方案
dotnet build

# 编译服务端
dotnet build Server.MirForms/Server.csproj

# Release 配置
dotnet build -c Release

# Debug 配置
dotnet build -c Debug
```

### 3.3 编译输出位置

| 配置 | 输出目录 |
|------|----------|
| Debug | `H:\github\Crystal\Build\Server\` |
| Release | `H:\github\Crystal\Build\Server\` |

## 5. 配置服务端

### 5.1 首次运行准备

1. **创建配置目录**
   ```bash
   cd H:\github\Crystal\Build\Server
   mkdir Configs
   mkdir Envir
   mkdir Envir\Drops
   mkdir Envir\Maps
   mkdir Envir\NPCs
   mkdir Envir\Goods
   mkdir Envir\Quests
   mkdir Logs
   ```

2. **复制配置文件**
   - 从源码目录复制配置文件（如果有模板）：
   ```bash
   # 如果源码中有 Configs 模板
   xcopy H:\github\Crystal\Server.MirForms\Configs H:\github\Crystal\Build\Server\Configs /E /I
   ```

3. **检查 Setup.ini**
   编辑 `Configs\Setup.ini`：

   ```ini
   [General]
   VersionPath=.\Mir2.Exe
   CheckVersion=False
   TestServer=False

   [Network]
   IPAddress=127.0.0.1
   Port=7000
   MaxUser=50

   [Permission]
   AllowNewAccount=True
   AllowChangePassword=True
   AllowLogin=True
   AllowNewCharacter=True
   ```

### 5.2 准备游戏数据

服务端需要以下数据文件（这些文件通常需要从原始项目获取）：

```
Build\Server\
├── Configs\
│   ├── Setup.ini
│   ├── ExpList.ini
│   ├── BaseStats.ini
│   └── ...
├── Envir\
│   ├── Account.DB              # 账号数据库
│   ├── Character.DB            # 角色数据库
│   ├── MonsterInfo.json        # 怪物信息
│   ├── MapInfo.json            # 地图信息
│   ├── ItemInfo.json           # 物品信息
│   ├── MagicInfo.json          # 技能信息
│   ├── NPCInfo.json            # NPC 信息
│   ├── Drops\                  # 掉落配置
│   ├── Maps\                   # 地图文件
│   └── NPCs\                   # NPC 脚本
```

⚠️ **注意**: 如果没有这些数据文件，服务端启动时会自动创建空的数据库文件。

## 6. 启动服务端

### 6.1 启动服务端

1. **打开服务端目录**
   ```
   H:\github\Crystal\Build\Server\
   ```

2. **运行 Server.exe**
   - 双击 `Server.exe`
   - 或在命令行中运行: `Server.exe`

3. **检查启动日志**
   服务端控制台应显示：
   ```
   Loading Configuration...
   Loading Database...
   Loading Maps...
   Server started on port 7000
   Waiting for connections...
   ```

首次启动时，服务端会自动创建 GM 账号（如果配置允许）：

- 默认 GM 密码: `admin`（可在 Setup.ini 中修改）

## 7. 配置客户端

客户端需要以下资源文件：

```
Build\Client\
├── Client.exe

│   └── ...\                   # 其他资源
```

## 8. 启动客户端并登录

### 8.1 启动客户端

1. **运行客户端**
   - 双击 `Client.exe`
   - 或在 Visual Studio 中按 `F5` 调试运行

2. **登录界面**
   - 服务器地址: `127.0.0.1`
   - 端口: `7000`（默认）

### 8.2 创建账号

1. **在登录界面点击"注册"**
   - 输入账号名
   - 输入密码
   - 确认密码

2. **或使用 GM 账号**
   - 账号: `admin`（或配置中设置的账号）
   - 密码: `admin`

### 8.3 创建角色

登录成功后：

1. **选择角色位置**（1-3 个空位）
2. **输入角色名**
3. **选择职业**
   - 战士 (Warrior)
   - 法师 (Wizard)
   - 道士 (Taoist)
   - 刺客 (Assassin)
   - 弓手 (Archer)
4. **选择性别**
5. **点击"创建"**

### 8.4 进入游戏

1. **选择已创建的角色**
2. **点击"进入游戏"**
3. **开始游戏！**

## 9. 常见问题

### 9.1 编译问题

**问题**: 找不到类型或命名空间
```
错误: 找不到类型或命名空间"ClientPackets"
```

**解决方案**:
1. 确保 `Shared` 项目已添加引用
2. 在 `.csproj` 中检查项目引用：
```xml
<ProjectReference Include="..\Shared\Shared.csproj" />
```

**问题**: 目标框架不匹配
```
错误: 项目的目标框架是 .NET 8.0
```

**解决方案**:
1. 安装 .NET 8.0 SDK
2. 或在项目属性中修改 TargetFramework

### 9.2 运行问题

**问题**: 服务端启动失败
```
错误: System.IO.FileNotFoundException: 无法加载文件
```

**解决方案**:
1. 检查 `Configs\Setup.ini` 是否存在
2. 检查 `Envir\` 目录是否创建
3. 确认所有依赖 DLL 都存在

**问题**: 客户端无法连接
```
错误: Connection failed
```

**解决方案**:
1. 确认服务端正在运行
2. 检查 IP 地址和端口配置
3. 检查防火墙设置
4. 尝试使用 `telnet 127.0.0.1 7000` 测试连接

**问题**: 登录后断开连接
```
错误: Disconnected from server
```

**解决方案**:
1. 检查服务端日志
2. 确认版本校验已关闭（`CheckVersion=False`）
3. 检查账号数据库

### 9.3 缺少资源文件

**问题**: 客户端启动后黑屏或无纹理
```
原因: 缺少 WIL/WTL 纹理库文件
```

**解决方案**:
1. 从原始游戏获取资源文件
2. 放入客户端的 `Data\` 目录
3. 确保文件路径正确

## 12. 网络配置

### 12.1 本地测试

使用默认配置即可：
```
服务器 IP: 127.0.0.1
端口: 7000
```

### 12.2 局域网连接

1. **获取服务器 IP**
   - 打开命令行，输入 `ipconfig`
   - 查找 IPv4 地址（如 192.168.1.100）

2. **修改服务端配置**
   ```ini
   [Network]
   IPAddress=0.0.0.0  # 监听所有网卡
   Port=7000
   ```

3. **修改客户端配置**
   ```ini
   [Server]
   IP=192.168.1.100  # 服务器 IP
   Port=7000
   ```

4. **防火墙设置**
   - 允许端口 7000 通过防火墙
   - 或临时关闭防火墙测试

### 12.3 公网连接

1. **路由器端口转发**
   - 转发外部端口 7000 到内部服务器 IP:7000

2. **使用公网 IP**
   - 客户端连接到公网 IP
   - 或使用域名 + DDNS
