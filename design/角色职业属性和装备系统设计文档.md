## 系统概述

Crystal 游戏采用**职业差异化**的角色属性系统和**多层次**的装备系统，具有以下特点：

- **五大职业**：战士、法师、道士、刺客、弓手各有特色
- **属性成长**：每个职业独特的HP/MP成长和主属性分配
- **丰富装备**：14个装备位，6种品质，多种属性类型
- **套装系统**：2-10件套的套装效果
- **觉醒强化**：装备可觉醒提升属性

### 核心设计理念

| 设计目标 | 实现方式 |
|---------|---------|
| **职业特色** | 独特的属性成长和装备类型 |
| **装备驱动** | 装备提供60%+的战斗力 |
| **成长深度** | 品质、强化、觉醒、套装 |
| **平衡性** | 各职业有明确优缺点 |

### 主属性分配

#### 属性点分配

```csharp
// 每升一级获得3点属性点
public byte StatPoints;

// 属性分配
Strength += 1;      // 力量：影响物理攻击和负重
Intelligence += 1;  // 智力：影响魔法攻击和MP
Agility += 1;       // 敏捷：影响命中、闪避和攻击速度
Luck += 1;          // 幸运：影响暴击和掉落
```

#### 属性作用

| 属性 | 主要作用 | 影响职业 |
|------|---------|---------|
| **力量** | 物理攻击力、负重 | 战士（主）、刺客 |
| **智力** | 魔法攻击力、MP上限 | 法师（主）、道士 |
| **敏捷** | 命中率、闪避率 | 刺客（主）、弓手 |
| **幸运** | 暴击率、掉落率 | 所有职业 |
| **准确率** | 命中率 | 弓手（主） |

#### 附加属性生成

```csharp
// 装备生成时随机附加属性
public void GenerateRandomStats(UserItem item)
{
    int statCount = GetRandomStatCount(item.Grade);  // 根据品质决定数量

    for (int i = 0; i < statCount; i++)
    {
        Stat randomStat = GetRandomStat(item.Info.Type);
        int amount = GetRandomAmount(randomStat, item.Grade);

        item.AddedStats.Add(new UserItemStat
        {
            Stat = randomStat,
            Amount = amount
        });
    }
}
```

### 攻击力计算

#### 物理攻击（DC）

```csharp
public int GetDC()
{
    // 1. 基础DC
    int minDC = Stats[Stat.MinDC];
    int maxDC = Stats[Stat.MaxDC];

    // 2. 装备加成
    foreach (var item in Equipment)
    {
        if (item != null)
        {
            minDC += item.Info.Stats.GetOrZero(Stat.MinDC);
            maxDC += item.Info.Stats.GetOrZero(Stat.MaxDC);

            // 附加属性
            foreach (var stat in item.AddedStats)
            {
                if (stat.Stat == Stat.MinDC) minDC += stat.Amount;
                if (stat.Stat == Stat.MaxDC) maxDC += stat.Amount;
            }

            // 觉醒属性
            if (item.Awake.Type == AwakeType.DC)
            {
                minDC += (item.Awake.Level + 1) * 2;
                maxDC += (item.Awake.Level + 1) * 2;
            }
        }
    }

    // 3. 幸运值影响（随机暴击）
    if (Envir.Random.Next(Luck + 1) > 0)
    {
        maxDC += (int)(maxDC * 0.1F);  // 暴击+10%伤害
    }

    return new int[] { minDC, maxDC };
}
```

```csharp
    // 2. 装备加成
    foreach (var item in Equipment)
    {

        {
            minAC += item.Info.Stats.GetOrZero(Stat.MinAC);
            maxAC += item.Info.Stats.GetOrZero(Stat.MaxAC);

            // 附加属性
            foreach (var stat in item.AddedStats)
            {
                if (stat.Stat == Stat.MinAC) minAC += stat.Amount;
                if (stat.Stat == Stat.MaxAC) maxAC += stat.Amount;
            }

            // 觉醒属性
```

### 生命值计算

#### HP上限

```csharp
public ushort MaxHP
{
    get
    {
        // 1. 基础HP
        ushort hp = (ushort)(BaseStats.HP + Level * Level * HPGrowth / 100);

        // 2. 装备加成
        foreach (var item in Equipment)
        {
            if (item != null)
            {
                hp += (ushort)item.Info.Stats.GetOrZero(Stat.HP);

                // 附加属性
                foreach (var stat in item.AddedStats)
                {
                    if (stat.Stat == Stat.HP) hp += (ushort)stat.Amount;
                }

                // 觉醒属性
                if (item.Awake.Type == AwakeType.HPMP)
                {
                    hp += (ushort)((item.Awake.Level + 1) * 20);
                }
            }
        }

        // 3. 百分比加成（套装等）
        foreach (var bonus in GetSetBonuses())
        {
            if (bonus.Stats.ContainsKey(Stat.HPPercent))
            {
                hp = (ushort)(hp * (1 + bonus.Stats[Stat.HPPercent]));
            }
        }

        return hp;
    }
}
```

### 攻击速度计算

```csharp
public int AttackSpeed
{
    get
    {
        // 1. 基础攻击速度（2500ms）
        int speed = 2500;

        // 2. 装备加成
        foreach (var item in Equipment)
        {
            if (item != null && item.Info.Stats.ContainsKey(Stat.AttackSpeed))
            {
                speed -= (int)item.Info.Stats[Stat.AttackSpeed];
            }
        }

        // 3. 硬性下限（550ms）
        return max(speed, 550);
    }
}
```
