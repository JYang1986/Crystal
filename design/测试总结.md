## ⚠️ 编译问题说明

### 遇到的问题

```
MSBUILD : error MSB1008: 只能指定一个项目。
```

**原因**: Git 的 `nologo` 命令被 MSBuild 误解析为参数。

**解决方案**:
1. ✅ 使用 Visual Studio IDE（推荐）
2. 或修改 Git 别名配置
3. 或使用完整的 MSBuild 参数

### 其他可能的编译问题

#### 1. 缺少引用

如果出现"找不到类型或命名空间"错误：

**检查文件是否存在**:
```
H:\github\mir2\Common.cs
H:\github\mir2\ClientPackets.cs
H:\github\mir2\ServerPackets.cs
```

**解决方案**: 确保这些文件在项目根目录

#### 2. .NET Framework 版本

```
错误: 项目的目标框架是 .NET Framework 4.5
```

**解决方案**:
- 安装 .NET Framework 4.5 Developer Pack
- 或在项目属性中升级到更高版本
