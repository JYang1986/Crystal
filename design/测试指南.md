## 🔧 编译指南

### 方法 1: 使用 Visual Studio（推荐）

1. **打开解决方案**
   ```
   双击: H:\github\mir2\Legend of Mir.sln
   ```

2. **设置启动项目**
   - 右键 `Client` 项目
   - 选择"设为启动项目"

3. **生成解决方案**
   - 按 `F6` 或点击"生成" → "生成解决方案"
   - 选择 `Release` 或 `Debug` 配置

4. **运行**
   - 按 `F5` 启动调试
   - 或按 `Ctrl+F5` 不调试运行

### 方法 2: 使用命令行

如果找到 Visual Studio 的 MSBuild 路径：

```bash
# 编译客户端
"D:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" "Client\Client.csproj" /p:Configuration=Release

# 或编译整个解决方案
"D:\Program Files\Microsoft Visual Studio\2022\Community\MSBuild\Current\Bin\MSBuild.exe" "Legend of Mir.sln" /p:Configuration=Release
```

### 方法 3: 使用 VS Code

如果安装了 VS Code：

1. 安装 C# 扩展
2. 打开项目文件夹
3. 按 `F5` 运行（需要配置 launch.json）

## ⚠️ 已知问题

### 编译问题

1. **缺少 MSBuild**
   - **原因**: 系统未找到 MSBuild 路径
   - **解决**: 需要找到 Visual Studio 的完整路径
   - **临时方案**: 使用 Visual Studio IDE 打开解决方案

2. **可能缺少引用**
   - `Common.cs`
   - `ClientPackets.cs`
   - `ServerPackets.cs`
   - **解决**: 确保这些文件在项目根目录

### 运行时问题

1. **缺少资源文件**
   - WIL/WTL 纹理库
   - 地图文件
   - 音效文件
   - **解决**: 需要从原始游戏复制资源文件

2. **存档文件不存在**
   - 第一次运行时没有存档
   - **解决**: 创建测试存档或实现角色创建功能

|------|------|------|
| `找不到类型或命名空间` | 缺少 using 引用 | 添加命名空间 |
