## 系统概述

Crystal 游戏采用**多层次、多功能**的背包和物品管理系统，具有以下特点：

- **多背包设计**：主背包、任务背包、仓库独立管理
- **动态扩展**：支持背包容量扩展
- **三级负重**：手持、穿戴、背包独立计算
- **智能堆叠**：自动合并相同物品
- **绑定系统**：多种保护模式
- **租赁机制**：支持物品租赁

### 核心设计理念

| 设计目标 | 实现方式 |
|---------|---------|
| **容量管理** | 格子限制、堆叠机制、扩展系统 |
| **负重控制** | 三级负重、移动限制、视觉提示 |
| **物品安全** | 绑定模式、账户锁、租赁保护 |
| **操作便利** | 快捷栏、自动堆叠、分类存储 |

## 负重系统

### 三级负重机制

Crystal 使用三个独立的负重属性：

```csharp
public float HandWeight;   // 手持负重
public float WearWeight;   // 穿戴负重
public float BackpackWeight; // 背包负重
```

### 负重计算

#### 负重上限

```csharp
// 从装备的 BagWeight 属性获取
public int BagWeight
{
    get
    {
        int weight = 0;
        // 遍历所有装备，累加 BagWeight 属性
        foreach (var item in Equipment)
        {
            if (item != null && item.Info.Stats.ContainsKey Stat.BagWeight])
            {
                weight += item.Info.Stats[Stat.BagWeight];
            }
        }
        return weight;
    }
}
```

**基础负重**：
- 角色等级影响
- 装备提供额外负重
- 力量属性可能加成

#### 当前负重计算

```csharp
public float BackpackWeight
{
    get
    {
        float weight = 0;
        // 遍历背包所有物品
        for (int i = 0; i < Inventory.Length; i++)
        {
            if (Inventory[i] != null)
            {
                weight += Inventory[i].Weight;  // 累加物品重量
            }
        }
        return weight;
    }
}
```

### 负重限制

#### 移动限制

| 负重比例 | 限制 | 说明 |
|---------|------|------|
| **0-50%** | 无限制 | 正常移动、奔跑 |
| **50-75%** | 警告 | 显示黄色提示 |
| **75-100%** | 无法奔跑 | 只能步行，显示红色 |
| **>100%** | 无法移动 | 完全无法移动 |

#### 检查逻辑

```csharp
// 检查是否可以奔跑
public bool CanRun
{
    get
    {
        float weightPercent = BackpackWeight / BagWeight;
        return weightPercent < 0.75F;  // 75%以下可奔跑
    }
}

// 检查是否可以移动
public bool CanMove
{
    get
    {
        return BackpackWeight <= BagWeight;  // 不超过上限
    }
}
```

### 负重显示

#### 颜色分级

```csharp
public Color WeightColor
{
    get
    {
        float percent = BackpackWeight / BagWeight;

        if (percent < 0.5F)
            return Color.Green;   // 绿色：安全
        else if (percent < 0.75F)
            return Color.Yellow;  // 黄色：警告
        else if (percent < 1.0F)
            return Color.Orange;  // 橙色：危险
        else
            return Color.Red;     // 红色：超重
    }
}
```

### 自动堆叠

#### 拾取时自动合并

```csharp
public bool CanAddItem(UserItem item)
{
    // 1. 检查是否有相同物品可堆叠
    for (int i = 0; i < Inventory.Length; i++)
    {
        if (Inventory[i] != null &&
            Inventory[i].Info == item.Info &&
            Inventory[i].Count < Inventory[i].Info.StackSize)
        {
            // 可堆叠
            int canAdd = Inventory[i].Info.StackSize - Inventory[i].Count;
            if (item.Count <= canAdd)
            {
                Inventory[i].Count += item.Count;
                return true;
            }
        }
    }

    // 2. 检查空格子
    for (int i = 0; i < Inventory.Length; i++)
    {
        if (Inventory[i] == null)
        {
            Inventory[i] = item;
            return true;
        }
    }

    return false;  // 背包已满
}
```

## 物品操作

### 基本操作

#### 使用物品

```csharp
public bool UseItem(int index)
{
    UserItem item = Inventory[index];

    // 1. 检查物品是否可用
    if (item == null || !item.Info.CanUse())
        return false;

    // 2. 执行使用效果
    switch (item.Info.Type)
    {
        case ItemType.Potion:
            UsePotion(item);
            break;
        case ItemType.Scroll:
            UseScroll(item);
            break;
        case ItemType.Book:
            LearnSkill(item);
            break;
        // ... 其他类型
    }

    // 3. 消耗物品
    if (item.Info.ConsumeOnUse)
    {
        item.Count--;
        if (item.Count <= 0)
            Inventory[index] = null;
    }

    return true;
}
```

#### 丢弃物品

```csharp
public bool DropItem(int index, int count)
{
    UserItem item = Inventory[index];

    // 1. 检查是否可丢弃
    if (item.Info.BindOnPickup || item.Info.AccountBound)
        return false;  // 绑定物品不可丢弃

    // 2. 检查数量
    if (count > item.Count)
        return false;

    // 3. 创建掉落物品
    UserItem dropItem = item.Clone();
    dropItem.Count = count;

    // 4. 从背包移除
    item.Count -= count;
    if (item.Count <= 0)
        Inventory[index] = null;

    // 5. 放置到地图
    CurrentMap.AddItemObject(this, dropItem);

    return true;
}
```

### 物品交易

#### 玩家交易

```csharp
public class PlayerTrade
{
    public PlayerObject Player;      // 交易对象
    public UserItem[] MyItems;       // 我方物品
    public UserItem[] TheirItems;    // 对方物品
    public uint MyGold;              // 我方金币
    public uint TheirGold;           // 对方金币
    public bool MyConfirmed;         // 我方确认
    public bool TheirConfirmed;      // 对方确认

    public bool CanTrade()
    {
        // 检查绑定物品
        foreach (var item in MyItems)
        {
            if (item != null && item.Info.BindOnPickup)
                return false;  // 拾取绑定不可交易
        }
        return true;
    }
}
```

## 特殊物品机制

### 绑定系统

#### 绑定类型

| 绑定类型 | 说明 | 交易 | 丢弃 | 存储 |
|---------|------|------|------|------|
| **无绑定** | 普通物品 | ✓ | ✓ | ✓ |
| **拾取绑定** | 拾取后绑定 | ✗ | ✓ | ✓ |
| **装备绑定** | 装备后绑定 | ✗ | ✓ | ✓ |
| **账户绑定** | 绑定到账户 | ✗ | ✓ | ✓ |
| **不可交易** | 完全不可交易 | ✗ | ✗ | ✓ |

#### 绑定检查

```csharp
public bool CanTrade(UserItem item)
{
    if (item.Info.BindOnPickup)
        return false;  // 拾取绑定
    if (item.Info.BindOnEquip && item.EquipCount > 0)
        return false;  // 装备绑定
    if (item.Info.AccountBound)
        return false;  // 账户绑定
    if (item.Info.NotTradable)
        return false;  // 不可交易
    return true;
}
```

public long GetRentalPrice(int days)
