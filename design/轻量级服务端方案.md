# Mir2 轻量级服务端架构设计

## 1. 架构概述

### 1.1 设计理念

```
原架构:
客户端 ──网络──> 服务端(完整游戏逻辑) ──网络──> 客户端
        ↑ 实时同步所有状态 ↓

新架构:
客户端 ──独立运行──> 本地游戏逻辑
        │
        └───网络──> 轻量服务端(仅统计+排名)
                   ↑ 仅上报统计数据
```

### 1.2 核心变化

| 组件 | 原架构 | 新架构 |
|------|--------|--------|
| **游戏逻辑** | 服务端处理 | 客户端本地处理 |
| **角色数据** | 服务端存储 | 客户端本地存储 |
| **战斗计算** | 服务端计算 | 客户端计算 |
| **怪物AI** | 服务端运行 | 客户端运行 |
| **网络通信** | 实时双向 | 异步上报 |
| **服务端职责** | 完整游戏 | 仅统计排名 |

## 6. 轻量服务端实现

### 6.1 服务端主程序

```csharp
// Server/LightServer/Program.cs
public class LightServer
{
    private TcpListener listener;
    private Dictionary<string, PlayerStatistics> players;
    private Dictionary<RankingType, List<RankingEntry>> rankings;

    public void Start()
    {
        // 只监听统计端口
        listener = new TcpListener(IPAddress.Any, 7000);
        listener.Start();

        // 接受客户端连接
        AcceptClients();
    }

    private void HandleClient(TcpClient client)
    {
        // 只处理统计相关数据包
        while (client.Connected)
        {
            var packet = ReceivePacket(client);

            switch (packet.Type)
            {
                case PacketType.Login:
                    HandleLogin(packet);
                    break;
                case PacketType.ReportStats:
                    UpdateStatistics(packet);
                    break;
                case PacketType.GetRanking:
                    SendRanking(client, packet);
                    break;
            }
        }
    }

    private void UpdateStatistics(StatsPacket packet)
    {
        // 更新玩家统计
        var stats = packet.Stats;
        players[stats.CharacterId] = stats;

        // 更新排行榜
        UpdateRankings();

        // 保存到数据库/文件
        SaveToFile();
    }
}
```

### 6.2 简化的数据包

### 7.2 统计收集器

```csharp
// Client/LocalGame/StatsCollector.cs
public class StatsCollector
{
    private PlayerStatistics stats;
    private LightServerClient serverClient;

    // 初始化
    public void Init(PlayerObject player)
    {
        stats = new PlayerStatistics
        {
            CharacterId = GenerateUniqueId(),
            CharacterName = player.Name,
            Class = player.Class,
            CreatedTime = DateTime.Now
        };
    }

    // 收集事件
    public void OnMonsterKilled(MonsterObject monster)
    {
        stats.MonstersKilled++;
        if (monster.IsBoss)
            stats.BossesKilled++;
    }

    public void OnLevelUp(ushort newLevel)
    {
        stats.Level = newLevel;
        stats.LevelUpTime = DateTime.Now;
        ReportToServer();  // 立即上报
    }

    public void OnItemEquip(ItemObject item)
    {
        UpdateGearScore();
    }

    // 定时上报
    public void StartAutoReport()
    {
        Timer timer = new Timer(5 * 60 * 1000);  // 每5分钟
        timer.Elapsed += (s, e) => ReportToServer();
        timer.Start();
    }

    // 上报到服务端
    private void ReportToServer()
    {
        stats.LastUpdateTime = DateTime.Now;
        stats.TotalPlayTime += (int)(DateTime.Now - lastReportTime).TotalSeconds;

        serverClient.SendStatistics(stats);
    }
}
```

## 12. 代码示例

### 12.1 客户端启动

```csharp
// Client/Program.cs
static void Main()
{
    // 1. 加载本地存档
    var character = LocalSaveManager.LoadCharacter();

    // 2. 初始化本地游戏环境
    LocalEnvir.Instance.Load();
    LocalEnvir.Instance.SetPlayer(character);

    // 3. 连接轻量服务端（异步）
    LightServerClient.Connect("127.0.0.1", 7000);
    LightServerClient.Login(character.Id);

    // 4. 启动统计收集
    StatsCollector.Instance.Init(character);
    StatsCollector.Instance.StartAutoReport();

    // 5. 运行游戏
    Application.Run(new CMain());
}
```

### 12.2 排行榜UI

```csharp
// Client/MirScenes/Dialogs/RankingDialog.cs
public class RankingDialog : MirImageControl
{
    private ComboBox categoryComboBox;
    private ListBox rankingList;

    public RankingDialog()
    {
        // 选择排行类型
        categoryComboBox.Items.AddRange(new[]
        {
            "等级排行",
            "装备评分",
            "击杀排行",
            "游戏时长"
        });

        categoryComboBox.SelectedIndexChanged += LoadRanking;
    }

    private async void LoadRanking()
    {
        var type = (RankingType)categoryComboBox.SelectedIndex;
        var ranking = await LightServerClient.GetRanking(type);

        rankingList.Items.Clear();
        foreach (var entry in ranking)
        {
            rankingList.Items.Add(
                $"#{entry.Rank} {entry.Name} - {entry.Value}"
            );
        }
    }
}
```

## 13. 部署方案

### 13.1 服务端部署

```
轻量服务端需求:
├── CPU: 单核即可
├── 内存: 512MB - 1GB
├── 带宽: < 1 Mbps
├── 存储: 10GB
└── 数据库: SQLite（或纯JSON文件）

硬件成本: 极低（可运行在树莓派上）
```

### 13.2 客户端发布

```
客户端包:
├── Mir2SP.exe              # 主程序
├── Data/                   # 游戏数据（100-500MB）
├── Resources/              # 资源文件（1-2GB）
└── Settings.ini            # 配置文件

安装包大小: ~3GB
```
