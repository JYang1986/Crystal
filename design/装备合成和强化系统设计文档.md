## 系统概述

Crystal 游戏采用多层次的装备提升系统，包括：

- **装备强化**：使用黑铁矿提升装备基础属性
- **装备觉醒**：使用特殊材料解锁装备潜力，获得额外属性加成
- **装备合成**：合并同类装备，叠加附加属性
- **配方制作**：使用材料和工具制作装备
- **宝石镶嵌**：在装备孔洞中镶嵌宝石获得特殊效果

## 装备强化系统

### 系统概述

装备强化是使用黑铁矿（BlackIronOre）提升装备基础属性的系统。强化成功会增加装备属性，失败可能导致属性降低。

### 配置参数

#### RefineSystem.ini
```ini
[Config]
OnlyRefineWeapon=True      # 只能强化武器
BaseChance=20             # 基础成功率 20%
Time=120                  # 强化时间 120秒
StatIncrease=1            # 每次强化属性加成 +1
CritChance=10             # 暴击几率 10%
CritIncrease=2            # 暴击时额外属性加成 +2
WepStatReducedChance=6    # 武器属性降低几率 6%
ItemStatReducedChance=15  # 装备属性降低几率 15%
RefineCost=125            # 强化消耗金币

[Ore]
OreName=BlackIronOre      # 强化矿石名称
```

#### Settings.cs 配置
```csharp
public static bool OnlyRefineWeapon = true;          // 只能强化武器
public static byte RefineBaseChance = 20;            // 基础成功率 20%
public static int RefineTime = 20;                   // 强化时间 20秒
public static byte RefineIncrease = 1;               // 每次强化属性 +1
public static byte RefineCritChance = 10;            // 暴击几率 10%
public static byte RefineCritIncrease = 2;           // 暴击额外加成 +2
public static byte RefineWepStatReduce = 6;          // 武器属性降低几率 6%
public static byte RefineItemStatReduce = 15;        // 装备属性降低几率 15%
public static int RefineCost = 125;                  // 强化消耗 125金币
public static string RefineOreName = "BlackIronOre"; // 强化矿石名称
```

### 强化流程

```
开始强化
  ↓
检查条件
  ├─ 是否在强化NPC附近
  ├─ 装备是否已有强化值（RefineAdded == 0）
  └─ 如果OnlyRefineWeapon=true，检查是否为武器
  ↓
消耗资源
  ├─ 消耗金币（RefineCost）
  └─ 消耗黑铁矿（BlackIronOre）
  ↓
开始强化计时（RefineTime）
  ↓
成功率判定
  ├─ 成功率：BaseChance（20%）
  ├─ 暴击判定：CritChance（10%）
  │   ├─ 触发暴击：属性 + RefineIncrease + CritIncrease（+1+2=+3）
  │   └─ 未触发暴击：属性 + RefineIncrease（+1）
  └─ 失败处理
      ├─ 武器失败：WepStatReducedChance（6%）降低属性
      ├─ 装备失败：ItemStatReducedChance（15%）降低属性
      └─ 强化值归零
  ↓
根据装备类型添加属性
  ├─ 武器：MinDC/MaxDC +1
  ├─ 头盔：MinAC/MaxAC +1
  ├─ 盔甲：MinAC +1
  └─ 其他：根据装备类型
  ↓
强化完成
```

### 强化属性加成规则

| 装备类型 | 强化属性 | 说明 |
|---------|---------|------|
| 武器 | MinDC/MaxDC | 物理攻击力 +1 |
| 头盔 | MinAC/MaxAC | 物理防御力/魔法防御力 +1 |
| 盔甲 | MinAC | 物理防御力 +1 |
| 项链 | MinMC/MaxMC | 魔法攻击力 +1 |
| 手镯 | MinAC/MaxAC | 物理防御力 +1 |
| 戒指 | MinMAC/MaxMAC | 魔法防御力 +1 |

### 成功率与风险

| 项目 | 概率 | 说明 |
|------|------|------|
| **基础成功率** | 20% | 强化成功的几率 |
| **暴击几率** | 10% | 触发暴击额外+2属性 |
| **武器失败降低属性** | 6% | 武器强化失败时降低属性 |
| **装备失败降低属性** | 15% | 装备强化失败时降低属性 |

### 强化限制

- **强化时间**：每次强化需要 20 秒
- **强化上限**：无明确限制（可根据需要添加）
- **失败惩罚**：不会销毁装备，只会降低属性或归零
- **装备限制**：默认只能强化武器（可配置）

## 装备觉醒系统

### 系统概述

装备觉醒是使用特殊材料解锁装备潜力的系统，可以获得额外的属性加成。觉醒分为 5 个等级，每个等级独立计算。

### 配置参数

#### AwakeningSystem.ini
```ini
[Attribute]
SuccessRate=70              # 觉醒成功率 70%
HitRate=70                 # 命中率 70%
MaxUpgradeLevel=5          # 最大觉醒等级 5

[IncreaseValue]
WeaponValue=1              # 武器觉醒倍率 1x
HelmetValue=1              # 头盔觉醒倍率 1x
ArmorValue=5               # 盔甲觉醒倍率 5x

[Value]
ChanceMax_Common=1         # 普通品级最大觉醒值 1
ChanceMax_Rare=2           # 稀有品级最大觉醒值 2
ChanceMax_Legendary=3      # 传说品级最大觉醒值 3
ChanceMax_Mythical=4       # 神话品级最大觉醒值 4
ChanceMax_Heroic=5         # 英雄品级最大觉醒值 5

[Materials_BaseValue]
DC_Common_Material1=1      # DC属性普通品级材料1数量
DC_Common_Material2=1      # DC属性普通品级材料2数量
# ... 其他属性配置
```

### 觉醒类型

```csharp

{
    None = 0,
    DC = 1,          // 攻击力
    MC = 2,          // 魔法攻击
    SC = 3,          // 道术攻击
    AC = 4,          // 防御力
    MAC = 5,         // 魔法防御
    HPMP = 6         // 生命/魔法值
}
```

### 觉醒流程

```
开始觉醒
  ↓
检查条件
  ├─ 装备是否支持觉醒（CanAwakening = true）
  ├─ 装备是否绑定到玩家
  ├─ 觉醒等级是否达到最大值（5级）
  └─ 根据装备类型限制觉醒属性类型
  ↓
消耗材料
  ├─ 材料1（根据觉醒类型和品级确定数量）
  └─ 材料2（根据觉醒类型和品级确定数量）
  ↓
成功率判定
  ├─ 成功率：SuccessRate（70%）
  ├─ 成功 → 继续
  └─ 失败 → 材料消耗，觉醒失败
  ↓
命中判定（5个等级独立计算）
  ├─ 每个等级独立判定命中率
  ├─ 命中率：HitRate（70%）
  └─ 生成命中数组：isHit[5]
  ↓
计算觉醒值
  ├─ 每个命中等级随机值：1-5
  ├─ 根据品级调整最大值
  │   ├─ 普通：最大 1
  │   ├─ 稀有：最大 2
  │   ├─ 传说：最大 3
  │   ├─ 神话：最大 4
  │   └─ 英雄：最大 5
  └─ 累加觉醒值
  ↓
应用装备倍率
  ├─ 武器：×1
  ├─ 头盔：×1
  └─ 盔甲：×5
  ↓
添加到装备属性
  ↓
觉醒完成
```

### 觉醒值计算示例

```csharp
// 觉醒值计算
private bool[] MakeHit(int maxValue, out int makeValue)
{
    bool[] isHit = new bool[5];
    makeValue = 0;

    for (int i = 0; i < 5; i++)
    {
        // 每个等级独立判定命中率（70%）
        if (rand.Next(0, 100) < AwakeHitRate)
        {
            isHit[i] = true;
            // 随机值 1 到 maxValue
            makeValue += rand.Next(1, maxValue + 1);
        }
    }

    return isHit;
}

// 应用装备倍率
if (item.Info.Type == ItemType.Armour) // 盔甲
{
    makeValue *= 5; // ×5倍率
}
else if (item.Info.Type == ItemType.Weapon ||
         item.Info.Type == ItemType.Helmet) // 武器或头盔
{
    makeValue *= 1; // ×1倍率
}
```

### 觉醒限制

- **最大觉醒等级**：5级
- **成功率**：70%
- **命中率**：每个等级 70%
- **装备限制**：必须支持觉醒（CanAwakening = true）
- **绑定限制**：装备必须绑定到玩家

## 装备合成系统

### 系统概述

装备合成系统允许玩家合并同类装备，叠加附加属性。主要包括装备合成、物品合并和配方制作。

### 装备合成（CombineItem）

#### 合成条件
- 两个装备必须类型相同
- 装备必须可叠加（StackSize > 1）
- 装备必须具有附加属性

#### 合成流程

```
开始合成
  ↓
检查条件
  ├─ 两个装备类型是否相同
  ├─ 装备是否可叠加（StackSize > 1）
  └─ 装备是否具有附加属性
  ↓
合成判定
  ├─ 成功率：85%
  ├─ 成功 → 附加属性叠加
  └─ 失败（15%）→ 材料装备被销毁
  ↓
结果处理
  ├─ 成功：目标装备附加属性增加
  └─ 失败：材料装备销毁
  ↓
合成完成
```

#### 合成示例

```csharp
// 合成前
装备A: DC+5, 附加属性: 攻击速度+10%
装备B: DC+5, 附加属性: 暴击率+5%

// 合成后（85%成功率）
装备A: DC+5, 附加属性: 攻击速度+10%, 暴击率+5%
装备B: 被销毁

// 失败（15%）
装备A: DC+5, 附加属性: 攻击速度+10%
装备B: 被销毁
```

### 物品合并（MergeItem）

#### 合并条件
- 两个物品必须相同
- 目标物品未达最大堆叠数

#### 合成流程

```
开始合并
  ↓
检查条件
  ├─ 两个物品是否相同
  └─ 目标物品是否达最大堆叠数
  ↓
计算可合并数量
  ├─ 可合并数量 = Min(材料物品数量, 目标物品最大堆叠数 - 目标物品当前数量)
  ↓
执行合并
  ├─ 材料物品数量 -= 可合并数量
  └─ 目标物品数量 += 可合并数量
  ↓
合并完成
```

### 配方制作（RecipeInfo）

#### 配方结构

```csharp

{
    public UserItem Item;           // 制作结果
    public List<UserItem> Ingredients; // 材料列表
```

```
[ingredients]

Hammer 1          # 铁锤x1
```

#### 制作流程

```
开始制作
  ↓
检查材料
  ├─ 检查所有材料是否充足
  └─ 检查所有工具是否可用
  ↓
消耗金币
  ↓
成功率判定
  ├─ 成功率：Chance（80%）
  ├─ 成功 → 继续
  └─ 失败 → 材料消耗，制作失败
  ↓
消耗材料和工具耐久
  ↓
生成制作结果
  ↓
制作完成
```

## 宝石镶嵌系统

### 系统概述

装备上的孔洞（Slots）可以镶嵌宝石，获得特殊的属性加成或效果。

### 孔洞系统

- **孔洞数量**：由装备的 `Slots` 属性决定
- **孔洞位置**：每个孔洞可以镶嵌一颗宝石
- **孔洞限制**：不能超过装备的最大孔洞数

### 宝石镶嵌规则

#### 装备类型与宝石匹配

```csharp
private bool ValidGemForItem(UserItem Gem, byte itemtype)
{
    switch (itemtype)
    {
        case 1: // 武器
            if (Gem.Info.Unique.HasFlag(SpecialItemMode.Paralize))
                return true;  // 麻痹宝石
            break;
        case 2: // 盔甲
            if (Gem.Info.Unique.HasFlag(SpecialItemMode.Teleport))
                return true;  // 传送宝石
            break;
        case 4: // 头盔
            if (Gem.Info.Unique.HasFlag(SpecialItemMode.ClearRing))
                return true;  // 清除戒指
            break;
        case 5: // 项链
            if (Gem.Info.Unique.HasFlag(SpecialItemMode.Protection))
                return true;  // 保护宝石
            break;
        case 6: // 手镯
            if (Gem.Info.Unique.HasFlag(SpecialItemMode.Revival))
                return true;  // 复活宝石
            break;
    }
    return false;
}
```

### 宝石镶嵌表

| 装备类型 | 可镶嵌宝石 | 特殊效果 |
|---------|-----------|----------|
| **武器** | 麻痹宝石 | 攻击时麻痹敌人 |
| **盔甲** | 传送宝石 | 受攻击时随机传送 |
| **头盔** | 清除戒指 | 清除负面状态 |
| **项链** | 保护宝石 | 减少受到的伤害 |
| **手镯** | 复活宝石 | 死亡时自动复活 |
| **戒指** | 力量宝石 | 增加攻击力 |
| **腰带** | 火焰宝石 | 火焰伤害 |
| **鞋子** | 治疗宝石 | 持续恢复HP |

### 镶嵌流程

```
开始镶嵌
  ↓
检查条件
  ├─ 装备是否有空孔洞
  ├─ 宝石是否匹配装备类型
  └─ 宝石是否已绑定
  ↓
消耗材料
  ├─ 宝石×1
  └─ 金币（可选）
  ↓
执行镶嵌
  ├─ 将宝石添加到装备孔洞
  └─ 宝石属性生效
  ↓
镶嵌完成
```

### 宝石摘除

- **摘除条件**：需要使用特殊道具
- **摘除结果**：宝石从孔洞中移除，可重新镶嵌
- **摘除风险**：部分宝石可能损坏（可配置）

## 配置参数

### 服务器配置（Settings.cs）


## 附录：完整示例

### 示例 1：装备强化

**场景**：
- 玩家有一把普通武器（MinDC=10, MaxDC=20）
- 玩家想要强化这把武器

**强化过程**：
1. 找到强化NPC
2. 放入武器和黑铁矿
3. 支付 125 金币
4. 等待 20 秒
5. 成功率判定（20%）
   - **成功（80%概率失败）**：
     - 暴击判定（10%）
       - 触发暴击：MinDC=10+3, MaxDC=20+3
       - 未触发暴击：MinDC=10+1, MaxDC=20+1
   - **失败**：
     - 武器属性降低判定（6%）
       - 触发降低：MinDC=10-1, MaxDC=20-1
       - 未触发：MinDC=10, MaxDC=20
     - 强化值归零

**结果**：
- 成功且暴击：DC +3
- 成功未暴击：DC +1
- 失败降低属性：DC -1
- 失败未降低：DC 0

### 示例 2：装备觉醒

**场景**：
- 玩家有一把稀有品质武器（品级=2）
- 玩家想要觉醒 DC 属性

**觉醒过程**：
1. 检查装备支持觉醒（CanAwakening = true）
2. 消耗材料（根据配置）
3. 成功率判定（70%）
   - **失败（30%）**：
     - 材料消耗，觉醒失败
   - **成功（70%）**：
     - 5个等级独立命中判定（每个70%）
     - 假设命中结果：[命中, 未命中, 命中, 命中, 未命中]
     - 每个命中等级随机值（1-2，稀有品级最大2）
     - 假设随机值：1, 0, 2, 1, 0
     - 总觉醒值：1+0+2+1+0 = 4
     - 应用武器倍率（×1）：4
     - 添加到装备：MinDC += 4, MaxDC += 4

**结果**：
- 失败：材料消耗，无变化
- 成功：DC +4（具体值根据命中和随机）

### 示例 3：宝石镶嵌

**场景**：
- 玩家有一把武器（1个孔洞）
- 玩家有一颗麻痹宝石

**镶嵌过程**：
1. 检查武器有空孔洞
2. 检查麻痹宝石匹配武器类型
3. 执行镶嵌
4. 武器获得麻痹效果

**结果**：
- 武器攻击时有概率麻痹敌人
