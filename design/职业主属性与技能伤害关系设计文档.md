## 系统概述

Crystal 游戏采用**装备驱动**的伤害系统，与传统 MMORPG 不同：

### 核心设计理念

- **装备为主**：技能伤害主要由装备的 DC/MC/SC 属性决定
- **等级为辅**：等级提供基础属性成长
- **主属性限制**：主属性（力量/智力/精神/敏捷）主要用于装备要求，不直接增加技能伤害
- **技能倍率**：技能等级提升伤害倍率

### 与传统 RPG 的区别

| 对比项 | 传统 RPG | Crystal |
|--------|----------|---------|
| **主属性作用** | 直接增加技能伤害 | 仅作为装备要求 |
| **伤害来源** | 主属性 × 技能倍率 | 装备属性 × 技能倍率 |
| **属性分配** | 玩家手动分配 | 等级自动成长 |
| **装备重要性** | 中等 | 极高 |

### 战士（Warrior）

#### 主属性：力量（Strength）

#### 基础属性配置（BaseStats.ini）

```ini
[Stats]
MinDC=0           # 最小物理攻击
MaxDC=5           # 最大物理攻击（每级 +5）
MinAC=0           # 最小物理防御
MaxAC=0           # 最大物理防御
MinMAC=0          # 最小魔法防御
MaxMAC=0          # 最大魔法防御
Agility=15        # 敏捷（影响闪避）
HP=14             # 基础生命值
MPGain=3.5        # 每级 MP 增长
HPGain=4          # 每级 HP 增长（最高）
```

| 属性 | 数值 | 说明 |
|------|------|------|
| **DC 成长** | +5/级 | 物理攻击力成长 |
| **HP 成长** | +4/级 | 最高的生命值成长 |
| **MP 成长** | +3.5/级 | 较低的魔法值成长 |
| **基础敏捷** | 15 | 中等闪避能力 |

#### 技能伤害类型

- **主要使用 DC（物理攻击）**

## 属性转换机制

### 攻击力计算公式

#### 基础攻击力（GetAttackPower）

```csharp
public int GetAttackPower(int min, int max)
{
    // 边界检查
    if (min < 0) min = 0;
    if (min > max) max = min;

    // 幸运值影响
    if (Stats[Stat.Luck] > 0)
    {
        // 正幸运值：有概率触发最大伤害
        if (Stats[Stat.Luck] > Envir.Random.Next(Settings.MaxLuck))
            return max;
    }
    else if (Stats[Stat.Luck] < 0)
    {
        // 负幸运值：有概率触发最小伤害
        if (Stats[Stat.Luck] < -Envir.Random.Next(Settings.MaxLuck))
            return min;
    }

    // 正常随机范围
    return Envir.Random.Next(min, max + 1);
}
```

#### 远程攻击力（GetRangeAttackPower）

```csharp
public int GetRangeAttackPower(int min, int max, int range)
{
    // 距离衰减
    decimal x = ((decimal)min / (Globals.MaxAttackRange)) * (Globals.MaxAttackRange - range);
    min -= (int)Math.Floor(x);
    return GetAttackPower(min, max);
}
```

### 属性成长公式

#### HP 成长公式

```csharp
// 战士特殊公式
HP = Base + (level / Gain + GainRate + level / 20F) * level

// 其他职业公式
HP = Base + (level / Gain + GainRate) * level
```

#### MP 成长公式

```csharp
// 法师公式
MP = Base + ((level / Gain + 2F) * 2.2F * level) + (level * GainRate)

// 道士公式
MP = (Base + level / Gain * 2.2F * level) + (level * GainRate)

// 其他职业公式
MP = Base + (level * Gain) + (level * GainRate)
```

#### 其他属性成长公式

```csharp
// DC/MC/SC 成长
Stat = Base + (level / Gain)
```

## 技能伤害计算

### 核心发现

**主属性（力量/智力/精神/敏捷）不直接影响技能伤害！**

技能伤害的驱动因素：
1. **装备 DC/MC/SC**（最关键）
2. **技能等级**
3. **Buff/Debuff**
4. **暴击**

### 技能伤害公式

#### 物理技能（战士、刺客）

```csharp
// 计算基础攻击力
int baseDamage = GetAttackPower(Stats[Stat.MinDC], Stats[Stat.MaxDC]);

// 计算技能伤害
int skillDamage = magic.GetDamage(baseDamage);

// GetDamage 内部计算
public int GetDamage(int DamageBase)
{
    return (int)((DamageBase + GetPower()) * GetMultiplier());
}
```

#### 魔法技能（法师、弓手）

```csharp
// 计算基础魔法攻击力
int baseDamage = GetAttackPower(Stats[Stat.MinMC], Stats[Stat.MaxMC]);

// 计算技能伤害
int skillDamage = magic.GetDamage(baseDamage);
```

#### 道术技能（道士）

```csharp
// 计算基础道术攻击力
int baseDamage = GetAttackPower(Stats[Stat.MinSC], Stats[Stat.MaxSC]);

// 计算技能伤害
int skillDamage = magic.GetDamage(baseDamage);
```

### 完整伤害公式

```
最终伤害 = [基础攻击力 + 技能威力] × 技能倍率 × 暴击倍率

其中：
基础攻击力 = 随机(MinDC ~ MaxDC)  // 来自装备和等级
技能威力 = (随机(MPowerBase ~ MPowerBase+MPowerBonus) / 4) × (技能等级 + 1) + 随机(PowerBase ~ PowerBase+PowerBonus)
技能倍率 = MultiplierBase + (技能等级 × MultiplierBonus)
暴击倍率 = 1（正常）或 2-3（暴击）
```

### 伤害计算示例

#### 战士技能伤害示例

**场景**：
- 战士等级 50
- 装备提供：MinDC=100, MaxDC=200
- 使用半月斩（HalfMoon），技能等级 3
- MagicInfo 配置：
  - PowerBase=20, PowerBonus=10
  - MPowerBase=10, MPowerBonus=5
  - MultiplierBase=1.0, MultiplierBonus=0.2

**计算过程**：
1. 基础攻击力：Random(100, 200) = 150
2. MPower = 10 + (3 × 5) + Random(5) = 28
3. Power = 20 + (3 × 10) + Random(10) = 53
4. 技能威力 = (28 / 4) × (3 + 1) + 53 = 81
5. 技能倍率 = 1.0 + (3 × 0.2) = 1.6
6. 最终伤害 = (150 + 81) × 1.6 = 369

**结果**：造成 369 点伤害

#### 法师技能伤害示例

**场景**：
- 法师等级 50
- 装备提供：MinMC=120, MaxMC=220
- 使用火球术（FireBall），技能等级 3
- MagicInfo 配置同上

**计算过程**：
1. 基础魔法攻击力：Random(120, 220) = 170
2. MPower = 10 + (3 × 5) + Random(5) = 28
3. Power = 20 + (3 × 10) + Random(10) = 53
4. 技能威力 = (28 / 4) × (3 + 1) + 53 = 81
5. 技能倍率 = 1.0 + (3 × 0.2) = 1.6
6. 最终伤害 = (170 + 81) × 1.6 = 401

**结果**：造成 401 点伤害

## 职业平衡分析

### DPS 排名（理论值）

基于 50 级、装备水平相同的情况下：

| 排名 | 职业 | 主要属性 | DPS 评价 | 特点 |
|------|------|----------|----------|------|
| 1 | **刺客** | DC=8/级 | 最高 DPS | 最高 DC 成长，高暴击 |
| 2 | **弓手** | DC+MC=8/级 | 高 DPS | 双攻击系统，高精准 |
| 3 | **法师** | DC+MC=7/级 | 中高 DPS | AOE 丰富，爆发高 |
| 4 | **道士** | DC+SC=7/级 | 中等 DPS | 召唤作战，持续输出 |
| 5 | **战士** | DC=5/级 | 中等 DPS | 坦度最高，稳定输出 |

| 排名 | 职业 | HP 成长 | 防御能力 | 生存评价 |
|------|------|---------|----------|----------|

| 2 | **道士** | +6/级 | 最高 MAC | 均衡防御 |
| 3 | **刺客** | +4/级 | 高闪避 | 高敏捷闪避 |
| 4 | **弓手** | +4/级 | 中等 | 距离优势 |
| 5 | **法师** | +1.5/级 | 最低 AC | 最脆皮 |

### 功能性排名

| 排名 | 职业 | 功能技能 | 团队价值 |
|------|------|----------|----------|
| 1 | **道士** | 治疗、隐身、复活 | 核心辅助 |
| 2 | **法师** | AOE、控制 | 群体输出 |
| 3 | **战士** | 坦克、控制 | 前排肉盾 |
| 4 | **弓手** | 陷阱、召唤 | 灵活输出 |
| 5 | **刺客** | 爆发、切入 | 单体爆发 |

### 职业定位总结

```
战士：高生存 + 稳定输出 = 坦克/战士
├─ 优点：最高 HP，稳定成长
├─ 缺点：DPS 相对较低
└─ 定位：前排肉盾，稳定输出

法师：高爆发 + AOE = 法师
├─ 优点：最高 AOE 伤害，技能丰富
├─ 缺点：最低生存能力
└─ 定位：后排输出，群体清怪

道士：全能辅助 = 道士
├─ 优点：治疗、召唤、隐身
├─ 缺点：单体输出较低
└─ 定位：团队核心，全能辅助

刺客：高爆发 + 高机动 = 刺客
├─ 优点：最高 DPS，高暴击
├─ 缺点：脆皮，近战
└─ 定位：单体爆发，快速击杀

弓手：远程 + 精准 = 弓手
├─ 优点：双攻击系统，高精准
├─ 缺点：需要预判
└─ 定位：远程输出，陷阱控制
```
