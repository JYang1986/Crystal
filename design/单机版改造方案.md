# Crystal Mir2 单机版改造方案

## 方案概述

将 Crystal Mir2 从网络游戏改造为单机游戏，采用**客户端服务端合并**的方案。

## 快速启动方案（本地回环）

### 第一步：配置本地服务端

编辑 `Server.MirForms/Configs/Setup.ini`:

```ini
[Network]
IPAddress=127.0.0.1
Port=7000

[Permission]
AllowNewAccount=True
AllowLogin=True
AllowNewCharacter=True
```

### 第二步：启动服务端

```bash
# 运行服务端
Build\Server\Server.exe
```

### 第三步：配置客户端连接本地

客户端默认连接 127.0.0.1:7000，启动即可：

```bash
# 运行客户端
Build\Client\Client.exe
```

### 第四步：开始游戏

1. 注册本地账号
2. 创建角色
3. 进入游戏

**效果**：你现在可以玩单机版了！（虽然仍有网络开销）

### 阶段 3: 本地数据存储

#### 创建 LocalSaveManager.cs

```csharp
using System.IO;
using System.Text.Json;

namespace Client.LocalGame
{
    public class LocalSaveManager
    {
        private static string SavePath = "./Saves/";

        public static void SaveCharacter(PlayerObject player)
        {
            // 保存角色数据到本地 JSON
            Directory.CreateDirectory(SavePath);

            var saveData = new
            {
                Name = player.Name,
                Level = player.Level,
                Experience = player.Experience,
                HP = player.HP,
                MP = player.MP,
                Map = player.CurrentMap,
                Location = player.Location,
                Inventory = player.Inventory.Items,
                Equipment = player.Equipment
            };

            string json = JsonSerializer.Serialize(saveData);
            File.WriteAllText(Path.Combine(SavePath, $"{player.Name}.json"), json);
        }

        public static PlayerObject LoadCharacter(string characterName)
        {
            // 从本地 JSON 加载角色
            string filePath = Path.Combine(SavePath, $"{characterName}.json");

            if (!File.Exists(filePath))
                return null;

            string json = File.ReadAllText(filePath);
            // 反序列化并创建角色对象
            return JsonSerializer.Deserialize<PlayerObject>(json);
        }
    }
}
```

### 阶段 4: 合并网络层（高级）

#### 创建 LocalProcessor.cs 替代 Network.cs

```csharp
namespace Client.LocalGame
{
    public class LocalProcessor
    {
        private Server.MirEnvir.Envir _environment;

        public LocalProcessor()
        {
            // 初始化本地环境
            _environment = new Server.MirEnvir.Envir();
        }

        public void ProcessAction(PlayerAction action)
        {
            // 直接处理玩家动作，不经过网络
            switch(action.Type)
            {
                case ActionType.Move:
                    _environment.MovePlayer(action.Target);
                    break;
                case ActionType.Attack:
                    _environment.PlayerAttack(action.Target);
                    break;
                case ActionType.UseItem:
                    _environment.UseItem(action.Item);
                    break;
                // ... 其他动作
            }
        }
    }
}
```

## 技术挑战

### 1. 服务端逻辑移植

**挑战**：将服务端逻辑移到客户端
- 战斗计算
- 怪物 AI
- 技能效果
- 掉落计算

**解决方案**：
- 创建 `GameLogic` 层
- 移植核心服务端类
- 保持数据结构一致

### 2. 性能优化

**挑战**：单机运行所有逻辑
- 客户端 + 服务端同时运行
- 内存占用增加
- CPU 负担增加

**解决方案**：
- 使用异步处理
- 优化 AI 更新频率
- 使用对象池减少 GC

### 3. 存档兼容性

**挑战**：版本更新后存档兼容
- 数据结构变化
- 新增字段

**解决方案**：
- 使用 JSON 格式（易于迁移）
- 版本号检查
- 默认值填充
